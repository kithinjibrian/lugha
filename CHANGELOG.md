## [Unreleased]

### Changed
- `lughac fmt` keeps an `if` with `else` whose branches are lone values on one line when it fits: `let y = if c { 1 } else { 2 };` (was five lines); chains break all or nothing (kivuli, session 235)
- `lughac test`'s summary counts files that didn't compile: `1 test: 1 passed, 0 failed, 1 file didn't compile`, and `"uncompiled":K` in the `--json` summary (kivuli, session 235)
- `lughac init --lib` writes the library as `src/lib.la` (its entry, with a module doc) and its example imports it as `import N;` (was `src/N.la` and `import N.N;`); E0312's help for `import N;` mentions the entry (milestone 99)
- A panic inside a std module reports a line two later than before (`<std>/math.la:62:9` instead of `60:9`): the std headers became module doc comments (milestone 98)
- `lughac check` no longer reports E0303 (only `build` and `run` do); `tests/programs/m3/e0303` moved to `tests/cli.rs`; `skip` is an intrinsic, so a function named `skip` is E0302; `--json`'s summary always carries `"skipped"` (v17, milestone 97)
- `actor` is a keyword (v17, milestone 92); E0211's message reads "`spawn` needs a call, or an actor to start"
- `spawn` and `select` are keywords (v17): a program using either as a name no longer compiles; `std.process`'s internal `spawn` and `$os.spawn` are now `start` and `$os.start` (its public API is unchanged); `import std.maths;`'s E0312 help lists `std.task`
- The VS Code extension (0.3.1) compiles from a clean `out/`: `npm run compile` (and so `npm test` and `npm run package`) removes it first, so files from older versions are neither tested nor packaged
- The VS Code extension is 0.3.0: it gained block-comment highlighting (milestone 76) and snippets (milestone 78) without a version bump, so a reinstalled `.vsix` could be skipped as already installed; its README now says to bump the version with every change
- A panic inside the prelude or a std module reports a later line than before (`<prelude>:154:9` instead of `135:9`, …): the bundled sources gained doc comments; the panics and their messages are unchanged
- The prelude moved into `src/prelude/`: `prelude.la` is `core.la`, and `prelude_iter.la`, `prelude_more.la`, `prelude_text.la` and `prelude_ops.la` are `iter.la`, `more.la`, `text.la` and `ops.la`; `lugha::PRELUDE` and compiled programs are unchanged
- `Checked` moved verbatim from `check/mod.rs` into `check/checked.rs` (approved split; `check/mod.rs` had reached 300 lines).
- Checker housekeeping: function bodies moved to `check/body.rs` and the array built-in methods to `check/builtins.rs`, keeping `stmt.rs` and `method_calls.rs` well under 300 lines
- The C runtime's source is split into three files under `runtime/` (core, stack overflow handler, printing) and joined into the same single `lugha_rt.c` at build time; compiled programs are unchanged

### Changed
- E0409 no longer rejects an extern returning `string`; `tests/programs/m3/e0409` now shows a callback returning a string, which stays E0409 (milestone 89)
- An extern parameter with a function type is now a callback instead of E0409; E0409's message for a function an extern would return says so (milestone 88)

### Fixed
- The expected type didn't reach a method call's receiver: `fun a(): Node<Msg> = leaf("x").pad(8);` was E0412. A receiver only its result types now takes the call's expected type when the method returns the receiver's own type, through chains (`.pad(1).pad(2)`), lists, tuples and `==`; hover shows the inferred type (kivuli, session 236)
- Inference from siblings didn't reach a call inside a tuple: `assert_eq(keyed_column([("a", text("a"))]), expected)` was E0412. A tuple holding a waiting call now waits too; tuples of literals keep their own types (kivuli, session 234)
- Doc comments didn't attach to `extern type` and `actor` declarations, so hover showed no doc for them; they now do, and spec §2 lists both (the user, session 231)
- A named import couldn't bring in an `extern type`: `import m { Handle };` and `public import m { Handle };` were E0301, while `m.Handle` worked; extern types now import and re-export by name like structs, and hover and Go to Definition reach them (kivuli's report, session 230). E0314's page now explains that a module is imported once per file, so `import m;` and `import m { X };` clash, and that `import m { X };` binds `m` too
- The names inside an import's braces (`import kivuli { text, column };`, and an `as` alias) were invisible to the editor: hover, Go to Definition, Find References and Rename now reach them as they reach any use, so renaming `text` also edits `{ text }` (the user, session 229)
- Inference from siblings reached only a waiting call itself: `assert_eq(column([text("a")]), expected)` was E0412. A generic call whose result's type parameter only waiting arguments could fix now waits too, as does a list or `Some` of waiting calls, and a list literal whose first element waits takes its type from the first element that doesn't (`[text("a"), button("+", Msg.Inc)]`) (kivuli's second report; milestone 96)
- `lughac check`/`test` of a package's `source` file from the package root resolved its imports of listed packages as its own modules (`kivuli.gtk.raw` not found), and from inside `source` it wasn't taken as the package's module at all; both now work from any folder (milestone 97)
- A package run from its own folder (its `examples/`) compiled and linked its `[link]` C files twice (`multiple definition`): the root manifest, read again as the implicit package, added its table twice. E0331's advice now follows the linker's message instead of always saying "install the missing library" (milestone 87)
- `lughac fmt` dropped the comma after a block arm even when the next arm started with `(` or `-`, so `{ 1 } (a, _)` re-parsed as a call and formatting failed its own check (exit 2); the comma now stays there (found by kivuli, session 218)
- A closure (or now a variant value) passed to a generic helper inside a generic function lost its parameter types when both named a type parameter alike (`fun lengths<T>(xs: T[][]): i64[] = xs.iter().map(fun(x) = x.len).collect();` was E0403 `fun({error}[])`): inference's hint replaced the caller's `T` as if it were the helper's. The hint is now built in one substitution (milestone 94)
- A handle named through its module (`m.H`, an `extern type` of another module) resolved to an error type without a diagnostic, so `fun(h: m.H)` closures failed with E0403 and `m.H` fields went unchecked; found while writing lugha-gtk (milestone 88's handles, session 192)
- `[link]` list mistakes say exactly what's wrong: `` `"z` in `libs` is missing its closing `"`: write `"z"` ``, a missing `]`, an unquoted item (`` write `"raylib"` ``), a `\` in a path; before, all four were one generic message (session 186)
- `lughac build`/`run`/`test` place the prelude after every loaded file, `lugha.toml` included, as the language server does: a diagnostic in a manifest found after checking (the new link codes) was otherwise shown in `<prelude>` (milestone 87)
- The language server published a `lugha.toml` error (E0325) to nothing once a program with loader errors was checked: the prelude's offsets overlapped the manifests'. The server now places the prelude after every loaded file (`modules::with_prelude_at`); the CLI never checked such programs and is unchanged

### Added
- Glob re-exports, milestone 100 (PRP-132): `public import raw { * };` makes every `public` item of `raw` (functions, externs, extern types, structs, enums, interfaces, and what `raw` re-exports by name) an item of this module; E0201 for `{ * }` without `public` or beside other names; E0314 at the `*` for a clash, naming both sources. Completion after `m.` now also lists what `m` re-exports, by name or glob (kivuli / lugha-gtk)
- Package entry modules, milestone 99 (PRP-131): `import kivuli;` imports the package's `lib.la` (at its module root) as the module `kivuli`, also as `import kivuli { X };` and `public import kivuli;`; `lughac test src/lib.la` names tests `kivuli.name`; `import N.lib;` is E0312
- Module doc comments, milestone 98 (PRP-130): a file's first `/** … */`, followed by a blank line or an `import`, documents its module; hovering a module's name (in an `import` or `m.f`) shows `module a.b` and that doc; the std modules' headers are now module docs
- `pkg-config --cflags` may give `-mfpmath=sse`, `-msse` and `-msse2` (exactly; PRP-129, approved by the user as a security decision): a package listing C files with `pkg-config = ["gtk4"]` no longer fails with E0329; every other `-m…` flag stays refused
- Packages and tests, milestone 97 (PRP-128): `lughac test`/`check` on a file in its package's `source` folder build it as the package's module (`glow.diff`; modules importing each other no longer E0319, tests named `glow.diff.name`); programs in a package's `test/`, `tests/`, `examples/` see its package-level items; `lughac check` takes a file without `main` as a library; `lugha.lock` sits beside the governing `lugha.toml` (an old lock beside the main file is read once, then written there); `skip(reason)` reports a test skipped (`... skipped (reason)`, `, S skipped`, `"skipped"` in `--json`, the VS Code Testing view; extension 0.13.0)
- Inference from siblings, milestone 96 (PRP-127): a call of a generic function whose type parameters appear only in its result (`text<M>(s): View<M>`) waits for its siblings — the other arguments of a generic call, the other operand of `==`/`!=`, the other side of `assert_eq`/`assert_ne` — and takes the type they fix; `assert_eq` now types a literal first argument from the second too (`assert_eq(3, x)` with `x: u8`), and `assert_eq(1, "a")` reports E0401 at `1` as `1 == "a"` does (found by kivuli)
- `lughac fmt` hugging, milestone 95 (PRP-126): a call's last argument that is an array or struct literal keeps the call's parentheses on its lines (`column([` … `])`) when the call doesn't fit but its first line does; nested calls hug too; a group now measures what follows it only up to the first place that can break, so `fun view(m: Model): View<Msg> = column([` keeps its header whole instead of breaking the parameter list. The printer gained `Hug`, `Broken` and `Huggable` (found by kivuli)
- Variants as function values, milestone 94 (PRP-125): a variant with payloads, not called, is `fun(payloads): E` — `Msg.Named`, `Shape.Rect`, `Some`, `Ok`, `Err`; a generic enum's variant takes its type arguments from the expected function type's result or parameters (`xs.iter().map(Some)`), E0412 otherwise; wrappers `lugha_ref_<Enum>.<Variant>`, one per variant. Programs not using it give byte-identical IR
- Struct update syntax, milestone 93 (PRP-124): `S { f: e, ..base }` takes every field not written from `base`, an expression of exactly the literal's struct type; the written fields are evaluated first, then `base` once (copied from a place, moved on its last use); `..` only last, once (E0201); another type is E0440, writing every field as well is warning W0104; every unwritten field must be visible (E0313). Programs without `..` give byte-identical IR
- Actors, milestone 92 (PRP-123): `actor Name { fields, methods }` declares state one green thread owns; `spawn Name { … }` or `spawn Name.new(…)` starts one and gives a handle of type `Name`; method calls on it are messages, handled one at a time (with a result: the caller waits; without: queued); built-in `stop()`, `join(): Option<string>`, `is`; a panic ends only its actor (`join` gives the message, waiting and later callers panic in turn); fields private; nothing that may hold a `Ref` crosses an actor's boundary. New code E0439. Runtime `runtime/actors.c`; every runtime panic now goes through one path (`panic_end`), output unchanged. VS Code extension 0.12.0: `actor` highlighted, an `actor` snippet
- VS Code extension 0.11.0: `spawn` and `select` highlighted as keywords, `after`/`default` only where they open a `select` arm, `Task` and `Chan` as built-in types (`test/grammar/tasks.la`); snippets `spawn`, `chan`, `select`, checked by `tests/snippets.rs`; README step 21
- Green threads, milestone 91 (PRP-122), opening Lugha v17 (`Language v17 Specification.md`; v16 frozen): `spawn f(x)` runs a call concurrently and gives a `Task<T>` (plain `Task` for a call returning nothing) whose `join()` waits for the result; `Chan<T>` with `Chan.new()`/`Chan.buffered(n)`, `send`, `recv` (`Option`, `None` once closed), `try_recv`, `close`, `is`; `select` with `name = c.recv()`, `c.send(v)`, `after(ms)` and `default` arms; `std.task` with `sleep(ms)` and `yield_now()`. All green threads share one OS thread (M:1): no `async`/`await`, no function colouring, no data races. A panic in any thread ends the program, `main` returning ends it, a deadlock panics; loops and calls in a program that spawns count down to preemption. New codes E0211 (`spawn` without a call, a malformed `select` arm) and E0438 (a `spawn` that changes a copy, a malformed `select`). Runtime: `runtime/tasks.c`, `spawn.c`, `chans.c` (1 MiB `mmap`'d stacks with guard pages, an x86-64 context switch, the collector told about every stack)

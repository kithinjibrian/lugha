## [Unreleased]

### Changed
- The prelude moved into `src/prelude/`: `prelude.la` is `core.la`, and `prelude_iter.la`, `prelude_more.la`, `prelude_text.la` and `prelude_ops.la` are `iter.la`, `more.la`, `text.la` and `ops.la`; `lugha::PRELUDE` and compiled programs are unchanged
- `Checked` moved verbatim from `check/mod.rs` into `check/checked.rs` (approved split; `check/mod.rs` had reached 300 lines).
- Checker housekeeping: function bodies moved to `check/body.rs` and the array built-in methods to `check/builtins.rs`, keeping `stmt.rs` and `method_calls.rs` well under 300 lines
- The C runtime's source is split into three files under `runtime/` (core, stack overflow handler, printing) and joined into the same single `lugha_rt.c` at build time; compiled programs are unchanged

### Added
- Format widths count characters, not bytes, and a fill may be any character (`{n:é^9}`); `runtime/format.c` pads by UTF-8 characters and writes the fill's UTF-8. `m46/more.stdout`'s `[{'é':^5}]` line becomes `[  é  ]` (was `[ é  ]`) — **milestone 63 complete**
- C → Lugha:
  - `parse_i64`, `parse_u64` and `string_from_utf8` are prelude functions (`text_parse_i64`, `text_parse_u64`, `text_from_utf8`);
  - `s.chars()` and `string_from_utf8` share one decoder (`utf8_decode`);
  - a bundled-only `$string.from_bytes` (`lugha_rt_str_from_bytes`) replaces `lugha_rt_utf8_check`, and `lugha_rt_parse_i64`/`_u64` are gone (`RUNTIME_SYMBOLS` 47 → 45);
  - a differential program matches the C implementation on every parser edge case and every two-byte UTF-8 input — **milestone 62 complete**
- One generic `iter_sum<T: Num>` behind `it.sum()` replaces the ten per-type prelude copies; nothing visible changes except the prelude line in `m36/overflow`'s panic (472 → 449) — **milestone 61 complete**
- Lazy std modules: an imported std module's non-generic functions and methods are compiled only when reached (calls, bounds, interface tables, function values), as the prelude's are; every body is still checked. One predicate (`check::instances::lazy_key`, `codegen::declare::is_lazy`) covers the prelude and std. IR lines with M59 → M60: a `seeded` + `below` program 423 → 314, `m54/below_panic` 430 → 321, `m54/random` 892 → 878, `m53/math` 246 → 241, firefly `mlp` 17,172 → 17,101 and `gpt` 17,927 → 17,856 — **milestone 60 complete**
- User-defined order: a struct or enum with `fun cmp(self, other: Self): Ordering` (a new prelude `enum Ordering { Less, Equal, Greater }`) is `Ord`; `<` `<=` `>` `>=` call `cmp`, tuples compare through it, and the new prelude helper `xs.sort()` sorts any `T: Ord` stably. E0404/E0419 help names the shape. A non-generic enum now prints by its key, so the prelude's is `$prelude.Ordering` in messages (and can't collide with a module's own `Ordering` in codegen's tables) — **milestone 59 complete**
- Numbers as `T`: `as` casts to and from type parameters bounded by `Num` or `Float` (E0408 with help otherwise); any integer literal as a `T: Num` and any float literal as a `T: Float`; E0402 per instance at the literal, naming the instance (`Checker::instance_literals`). glowworm's `arange`, `linspace` and `mean` use them, with the same output — **milestone 58 complete**
- Nested `mut self` calls: E0508 now rejects only an argument that can be the receiver's own storage (a place rooted at the receiver, of a pointer-passed type, also as an `if`/block/`match` tail), so `g.tanh(g.add(a, b))` and `g.scale(x, g.lr)` are valid; a `mut self` call plans its receiver, runs its arguments, then reaches the receiver (direct and interface calls); E0510 for a receiver only across an index. `places.rs::place_address` is gone. firefly's GPT layer is written nested, with identical output — **milestone 57 complete**
- Owning arrays once per loop: before every loop (`for … in`, `for … of`, `for … of mut`, iterator loops, `while`, `while let`), the compiler makes unique the arrays the loop writes through when a syntactic scan shows the loop can't share them again (`codegen/hoist.rs`, `codegen/hoist_scan.rs`); writes inside skip the copy-on-write flag test. Indexed paths are hoisted when their indexes are fixed, with a guarded bounds test that skips instead of panicking. No program's output changes. Timings: DECISION-010's benchmarks on a quiet machine, best of 7 (pre-copy-on-write → M55 → M56): histogram 130 → 203 → 145 ms, matmul 131 → 173 → 133 ms, life 411 → 415 → 413 ms, sort 146 → 150 → 140 ms; interleaved M55 → M56 under load: particles 107 → 85 ms, sort_swap 134 → 123 ms, firefly mlp 4.54 → 4.19 s, gpt 1000 steps 15.7 → 14.5 s; every output identical — **milestone 56 complete**
- Copy-on-write arrays: a copy site marks an array shared (the top bit of `cap`) instead of copying it, and a write clones a shared array one level first, through two-phase places (indexes and bounds checks, then the value, then owning each array from the root). `swap` plans both places before writing; `for … of mut` re-reaches its place on every use. No program's output changes. Timings: firefly `mlp` on 32k names 5.25 s → 4.06 s (3.32 s in an earlier run); `gpt` 1000 steps 20.06 s → 13.82 s (12.93 s earlier); `gpt` 6000 steps 1 m 43 s → 1 m 30 s; DECISION-010's benchmarks (best of 5, ms): histogram 140 → 217, life 434 → 438, matmul 143 → 188, particles_inplace 25 → 27, particles 140 → 86, sort 165 → 159, sort_swap 116 → 123; glowworm's examples unchanged (≤ 0.05 s); every output identical — **milestone 55 complete**
- `std.random`: a xoshiro256\*\* `Rng` (splitmix64 seeding) written in Lugha, made by `random.seeded(seed)` or `random.from_os()` (new runtime fragment `runtime/random.c`, `lugha_rt_os_seed`: `getrandom`, else `/dev/urandom`), with `next_u64`, `uniform`, `below`, `between`, `normal`, `chance`, `choice` and `shuffle`; not cryptographically secure.

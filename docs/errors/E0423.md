# E0423: Two bounds declare one item differently

A type parameter with several bounds, `T: A + B`, gets the items of all of
them. If two bounds declare an item with the same name but different
signatures, a call like `x.size()` would have no single meaning, and no type
could satisfy both, so the bound list is rejected.

```lugha
interface Sized {
    fun size(self): i64;
}

interface Measured {
    fun size(self): f64;
}

fun show<T: Sized + Measured>(x: T) { // error: E0423
    println(x.size());
}

fun main() {}
```

Give the methods different names, or make them agree:

```lugha
interface Sized {
    fun size(self): i64;
}

interface Measured {
    fun length(self): f64;
}

fun show<T: Sized + Measured>(x: T) {
    println(x.size());
    println(x.length());
}

fun main() {}
```

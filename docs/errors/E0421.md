# E0421: A method no bound declares

Inside a generic function, a value of type `T` can only use what `T`'s
bounds declare. The function is checked once, for every type it might be
called with, so it can't rely on a method that one particular argument
happens to have. Here `Square` has `perimeter`, but `Shape` doesn't promise
it:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Square {
    fun area(self): f64 = self.side * self.side;
    fun perimeter(self): f64 = 4.0 * self.side;
}

fun report<T: Shape>(s: T) {
    println(s.area());
    println(s.perimeter()); // error: E0421
}

fun main() {
    report(Square { side: 2.0 });
}
```

Declare the method in the interface, so every `T` that satisfies it has
one:

```lugha
interface Shape {
    fun area(self): f64;
    fun perimeter(self): f64;
}

struct Square { side: f64 }

impl Square {
    fun area(self): f64 = self.side * self.side;
    fun perimeter(self): f64 = 4.0 * self.side;
}

fun report<T: Shape>(s: T) {
    println(s.area());
    println(s.perimeter());
}

fun main() {
    report(Square { side: 2.0 });
}
```

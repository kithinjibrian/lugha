# E0449: Retired in v17

This code is never reported and will never be reused for anything else.

For one milestone of v17 (133), lughac could build for Linux on ARM64 but
didn't yet know how ARM's C compilers pass a struct by value, so an
`extern struct` crossing to or from C by value was E0449 on
`aarch64-unknown-linux-gnu`. Milestone 134 added those rules (AAPCS64), so
the same declarations build on both targets:

```lugha
extern struct Rect { w: f64, h: f64 }
extern fun area(r: Rect): f64;

fun main() {
    println(area(Rect { w: 2.0, h: 3.0 }));
}
```

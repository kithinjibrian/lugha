# E0442: `for … of mut` over a map or set

`for x of mut e` changes each element of an array in place. Maps and sets
aren't changed through their loops: a loop visits a copy of their entries,
and a set's values or a map's keys can't be changed where they are.

```lugha
fun main() {
    let mut scores = #{"ann": 3, "bo": 5};
    for (name, score) of mut scores { // error: E0442
        println(name);
    }
}
```

Loop over the keys and assign each entry:

```lugha
fun main() {
    let mut scores = #{"ann": 3, "bo": 5};
    for name of scores.keys() {
        scores[name] = scores[name] + 1;
    }
    println(scores);
}
```

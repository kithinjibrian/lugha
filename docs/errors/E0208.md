# E0208: `import` after an item

Every `import` in a file comes before its first other declaration. That
way the top of a file lists everything it depends on, and a reader never
has to search the whole file for imports.

```lugha
fun half(x: f64): f64 = x / 2.0;

import std.math; // error: E0208

fun main() {
    println(half(math.sqrt(16.0)));
}
```

Move the import to the top:

```lugha
import std.math;

fun half(x: f64): f64 = x / 2.0;

fun main() {
    println(half(math.sqrt(16.0)));
}
```

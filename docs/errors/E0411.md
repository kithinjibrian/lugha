# E0411: Not indexable or not iterable

A value was indexed with `[…]` or looped over with `for … of`, but its
type supports neither. Arrays and strings can be indexed; arrays,
strings, iterators and types with a `fun next(mut self): Option<T>`
method can be looped over. Other values, such as a plain number, have no
elements.

```lugha
fun main() {
    let n = 42;
    println(n[0]); // error: E0411
}
```

Index an array, or use the number directly:

```lugha
fun main() {
    let ns = [42];
    println(ns[0]);
}
```

To loop a number of times, use a range with `in`, not `of`:

```lugha
fun main() {
    for c of 5 { // error: E0411
        println(c);
    }
}
```

```lugha
fun main() {
    for c in 0..5 {
        println(c);
    }
}
```

Your own struct, enum or interface can be indexed by giving it the
methods `[ ]` calls: `fun index(self, i: I): T` to read `a[i]`, and
`fun set_index(mut self, i: I, v: T)` to write `a[i] = v`. Several
indexes are one tuple: `a[x, y]` is `a[(x, y)]`.

```lugha
struct Grid { w: i64, cells: f64[] }

fun main() {
    let g = Grid { w: 2, cells: [0.0; 4] };
    println(g[1, 0]); // error: E0411
}
```

```lugha
struct Grid { w: i64, cells: f64[] }

impl Grid {
    fun index(self, at: (i64, i64)): f64 {
        let (r, c) = at;
        self.cells[r * self.w + c]
    }
}

fun main() {
    let g = Grid { w: 2, cells: [0.0; 4] };
    println(g[1, 0]);
}
```

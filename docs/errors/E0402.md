# E0402: Integer literal out of range for its type

An integer literal doesn't fit the type it is given. A `u8` holds 0 to
255, an `i32` about plus or minus two billion, and so on; a literal beyond
its type's range is rejected when the program is checked rather than
quietly wrapping when it runs.

```lugha
fun main() {
    let b: u8 = 256; // error: E0402
    println(b);
}
```

Negative literals count too: `let n: u32 = -1;` is out of range, because
unsigned types start at 0.

Use a wider type, or a value that fits:

```lugha
fun main() {
    let b: u16 = 256;
    println(b);
}
```

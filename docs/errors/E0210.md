# E0210: An unknown or misplaced attribute

An attribute `@name` sits before an item. Lugha has one attribute,
`@test`, and it goes only before a function, marking it as a test that
`lughac test` runs. Any other name, or `@test` before a struct, an enum
or anything else, is this error; the item itself is still read.

```lugha
@inline // error: E0210
fun double(x: i64): i64 = x * 2;

fun main() {
    println(double(21));
}
```

Remove the attribute:

```lugha
fun double(x: i64): i64 = x * 2;

fun main() {
    println(double(21));
}
```

`@test` belongs on a function, not on the type it tests:

```lugha
@test // error: E0210
struct Point { x: i64, y: i64 }

fun main() {
    println(Point { x: 1, y: 2 }.x);
}
```

```lugha
struct Point { x: i64, y: i64 }

@test
fun point_holds_x() {
    assert(Point { x: 1, y: 2 }.x == 1);
}

fun main() {
    println(Point { x: 1, y: 2 }.x);
}
```

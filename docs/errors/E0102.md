# E0102: Unterminated string

A string literal was opened with `"` but never closed. In Lugha a string
ends on the line it starts, so a missing `"` is caught right there rather
than swallowing the rest of the file.

```lugha
fun main() {
    println("hello, world); // error: E0102
}
```

Close the string:

```lugha
fun main() {
    println("hello, world");
}
```

A string can't run across lines either. Write `\n` where the line break
should go:

```lugha
fun main() {
    println("first line // error: E0102
second line");
}
```

```lugha
fun main() {
    println("first line\nsecond line");
}
```

# E0514: `break` with a value out of a `while` or `for` loop

Only `loop` gives a value: `let x = loop { … break v; };`. A `while` or
`for` loop can end without a `break` (its condition fails, or its values
run out), and then there would be no value, so a `break` leaving one
can't carry one.

```lugha
fun main() {
    let xs = [3, 8, 5];
    for x of xs {
        if x > 4 {
            break x; // error: E0514
        }
    }
}
```

Wrap the search in a `loop`, and say what it gives when nothing is found:

```lugha
fun main() {
    let xs = [3, 8, 5];
    let first = search: loop {
        for x of xs {
            if x > 4 {
                break search Some(x);
            }
        }
        break None;
    };
    println(first);
}
```

A `break` inside the `for` targets the `for` unless it names the `loop`.

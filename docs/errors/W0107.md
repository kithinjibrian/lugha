# W0107: A leading zero that looks octal

In Lugha a leading zero doesn't make a number octal: `0600` is six hundred.
That's rarely what was meant — permission modes are the usual case, where
0600 means "owner reads and writes" — so it gets a warning.

```lugha
fun main() {
    let mode = 0600; // warning: W0107
    println(mode);
}
```

Write `0o` for octal (v17), or drop the zero for decimal:

```lugha
fun main() {
    let mode = 0o600;
    println(mode);
}
```

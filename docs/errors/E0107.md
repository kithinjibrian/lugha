# E0107: Float needs a fractional part

A float literal with an exponent must also have a `.` and a digit after
it. Lugha keeps the rule simple: a number is a float exactly when it has
a `.`, so `2e5` could be read either way and is rejected.

```lugha
fun main() {
    let speed = 2e5; // error: E0107
    println(speed);
}
```

Add the fractional part:

```lugha
fun main() {
    let speed = 2.0e5;
    println(speed);
}
```

# E0401: Numeric literal of the wrong kind for its expected type

A float literal such as `2.5` was used where an integer type is expected,
or an integer literal such as `2` where a float type is expected. Lugha has
no implicit conversions, so a literal takes the type its place asks for,
and `2.5` can't become an `i32` any more than `2` can silently become an
`f64`. Keeping the two kinds apart means you never lose a fraction by
accident.

```lugha
fun main() {
    let x: i32 = 4;
    let y = x + 2.5; // error: E0401
    println(y);
}
```

Write the literal in the kind the expression needs, or cast the other
operand with `as` so that the whole expression is a float:

```lugha
fun main() {
    let x: i32 = 4;
    let y = x as f64 + 2.5;
    println(y);
}
```

The same goes the other way: a float annotation needs a float literal.
Write `3.0`, not `3`:

```lugha
fun main() {
    let ratio: f64 = 3.0;
    println(ratio);
}
```

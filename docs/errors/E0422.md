# E0422: A type argument, or a converted value, doesn't satisfy an interface

A type satisfies an interface when it has every method the interface
declares, with the same receiver, parameters and result. Nothing needs
declaring: the compiler checks it wherever the type is used as `T: Shape`
or a value is converted to the interface type `Shape`. This error says that
check failed, and the message names the missing item.

```lugha
interface Shape {
    fun area(self): f64;
}

fun total_area<T: Shape>(shapes: T[]): f64 {
    let mut sum = 0.0;
    for s of shapes {
        sum += s.area();
    }
    sum
}

fun main() {
    println(total_area([1, 2])); // error: E0422
}
```

Numbers have no `area` method. The same error comes from `let s: Shape = 1;`
and from converting one interface value to another interface whose items it
doesn't all have.

Pass values of a type that has the method:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Square {
    fun area(self): f64 = self.side * self.side;
}

fun total_area<T: Shape>(shapes: T[]): f64 {
    let mut sum = 0.0;
    for s of shapes {
        sum += s.area();
    }
    sum
}

fun main() {
    println(total_area([Square { side: 1.0 }, Square { side: 2.0 }]));
}
```

# E0429: A `let … else` whose `else` block can finish

`let Some(n) = o else { … };` binds `n` when the pattern matches and runs
the `else` block when it doesn't. After the statement the code uses `n`, so
if the pattern failed there must be no way to get there: the `else` block
has to leave, with `return`, `break`, `continue` or a call like `panic` or
`exit`. One that can run to its end would leave `n` without a value.

```lugha
fun main() {
    let o = parse_i64("x");
    let Some(n) = o else { // error: E0429
        println("not a number");
    };
    println(n);
}
```

End the `else` block by leaving:

```lugha
fun main() {
    let o = parse_i64("x");
    let Some(n) = o else {
        println("not a number");
        return;
    };
    println(n);
}
```

To carry on with a fallback value instead, use `unwrap_or` or a `match`:

```lugha
fun main() {
    let n = parse_i64("x").unwrap_or(0);
    println(n);
}
```

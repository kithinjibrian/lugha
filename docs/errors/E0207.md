# E0207: `::` used as a path separator

Lugha separates path parts with `.`, as in `Shape.Circle` or
`geometry.Point`; `::` isn't an operator. The error comes with the fix,
and parsing continues as if `.` had been written, so other errors in the
file are still found.

```lugha
enum Shape { Circle(f64), Square(f64) }

fun main() {
    let s = Shape::Circle(1.0); // error: E0207
    match s {
        Circle(r) => println(r),
        Square(w) => println(w),
    }
}
```

Write `.`:

```lugha
enum Shape { Circle(f64), Square(f64) }

fun main() {
    let s = Shape.Circle(1.0);
    match s {
        Circle(r) => println(r),
        Square(w) => println(w),
    }
}
```

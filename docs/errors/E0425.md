# E0425: An interface with an associated function used as a type

An interface value holds one concrete value and calls its methods through
it. An associated function, one without `self`, such as `fun make():
Factory;`, has no value to be called on, so an interface value couldn't
call it. Such an interface can be a bound but not a type.

```lugha
interface Factory {
    fun make(): Factory;
}

fun build(f: Factory) {} // error: E0425

fun main() {}
```

Use the interface as a bound on a type parameter instead, where the
concrete type is known and `T.make()` can be called:

```lugha
interface Maker {
    fun make(): Self;
    fun name(self): string;
}

struct Widget { id: i64 }

impl Widget {
    fun make(): Widget = Widget { id: 1 };
    fun name(self): string = "widget {self.id}";
}

fun build<T: Maker>(sample: T): string = sample.name();

fun main() {
    println(build(Widget.make()));
}
```

# E0426: A type pattern that can't apply

A type pattern, `c: Circle`, asks an interface value which concrete type it
holds. It only makes sense on an interface value, naming a concrete type
that satisfies that interface. On anything else the arm could never match,
which is almost always a mistake, so it is an error rather than a dead arm.

```lugha
struct Circle { r: f64 }

fun main() {
    let n = 5;
    match n {
        c: Circle => println("a circle"), // error: E0426
        _ => println("not a circle"),
    }
}
```

Match type patterns on an interface value, naming types that satisfy the
interface:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Circle { r: f64 }

impl Circle {
    fun area(self): f64 = 3.0 * self.r * self.r;
}

fun describe(s: Shape): string = match s {
    c: Circle => "circle of radius {c.r}",
    _ => "some shape",
};

fun main() {
    println(describe(Circle { r: 1.0 }));
}
```

The same error comes from a type the interface value can never hold, here
`Dot`, which has no `area`:

```lugha
interface Shape {
    fun area(self): f64;
}

struct Circle { r: f64 }

impl Circle {
    fun area(self): f64 = 3.0 * self.r * self.r;
}

struct Dot { x: f64 }

fun describe(s: Shape): string = match s {
    c: Circle => "circle of radius {c.r}",
    d: Dot => "a dot", // error: E0426
    _ => "some shape",
};

fun main() {
    println(describe(Circle { r: 1.0 }));
}
```

# E0301: Undefined name

A name was used that nothing in scope defines: no local, parameter,
function, constant or imported item is called that. Most often it is a
typo, a binding declared inside a block and used outside it, or a function
from another module used without its module name.

```lugha
fun main() {
    let total = 2;
    println(totl + 1); // error: E0301
}
```

Check the spelling, and that the binding is declared before the line that
uses it, in the same block or an enclosing one:

```lugha
fun main() {
    let total = 2;
    println(total + 1);
}
```

A binding declared inside a block ends with that block. Declare it outside
if the code after the block needs it:

```lugha
fun main() {
    let mut big = false;
    if 3 > 2 {
        big = true;
    }
    println(big);
}
```

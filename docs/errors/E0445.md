# E0445: Not a constant

A constant (`const NAME: T = value;`) is computed once, before `main`, from
its value alone. So the value may use only literals, other constants,
`I.MIN`/`I.MAX`, operators, `as`, and array, struct, tuple and variant
literals made of those — no function calls, closures, `if`, blocks,
interpolation, `#{…}` or locals. And its type must be plain data: numbers,
`bool`, `char`, strings, `()`, and arrays, structs, tuples and enums of
those — not functions, `Ref`, tasks, channels, actors, handles, maps or sets.

```lugha
fun square(x: i64): i64 = x * x;

const AREA: i64 = square(4); // error: E0445

fun main() {
    println(AREA);
}
```

Write the value out, or compute it where it's used:

```lugha
const SIDE: i64 = 4;
const AREA: i64 = SIDE * SIDE;

fun main() {
    println(AREA);
}
```

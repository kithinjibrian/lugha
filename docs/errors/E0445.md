# E0445: Not a constant

A constant (`const NAME: T = value;`) is computed once, before `main`. Its
value may be any expression, calls included, as long as it is *pure*:
nothing it runs, directly or through the functions it calls, may reach
outside the program. That rules out printing, reading input or the command
line, reading or writing files, anything in std that uses the operating
system (files, the network, the clock, the environment, random numbers,
processes), calling an `extern` C function, `exit`, and starting tasks,
channels or actors. Local variables, loops, recursion, arrays, maps, `Ref`,
closures and `panic` are all fine. The help shows the path to what isn't
pure.

A constant's type must also be plain data: numbers, `bool`, `char`,
strings, `()`, and arrays, structs, tuples and enums of those — not
functions, `Ref`, tasks, channels, actors, handles, maps or sets.

```lugha
fun load(): string = match read_file("app.toml") {
    Ok(text) => text,
    Err(_) => "",
};

const CONFIG: string = load(); // error: E0445

fun main() {
    println(CONFIG);
}
```

Compute the value in `main` and pass it on:

```lugha
fun load(): string = match read_file("app.toml") {
    Ok(text) => text,
    Err(_) => "",
};

fun main() {
    let config = load();
    println(config);
}
```

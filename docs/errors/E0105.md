# E0105: Misplaced `_` in a number

An `_` in an integer literal groups digits, as in `1_000_000`, and it must
sit between two digits. Two in a row, one at the start or end, or one
right after a prefix such as `0x` is an error. Float literals take no `_`
at all.

```lugha
fun main() {
    let million = 1__000_000; // error: E0105
    println(million);
}
```

Use a single `_` between digits:

```lugha
fun main() {
    let million = 1_000_000;
    println(million);
}
```

In a float, leave the `_` out:

```lugha
fun main() {
    let rate = 1_0.5; // error: E0105
    println(rate);
}
```

```lugha
fun main() {
    let rate = 10.5;
    println(rate);
}
```

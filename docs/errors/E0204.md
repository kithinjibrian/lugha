# E0204: Assignment used as an expression

An assignment (`=`, `+=` and the rest) is a statement in Lugha, not an
expression with a value. So it can't sit inside a condition, an argument
or another assignment. That rules out the classic slip of `=` for `==`.

```lugha
fun main() {
    let x = 1;
    if x = 1 { // error: E0204
        println("one");
    }
}
```

To compare, write `==`:

```lugha
fun main() {
    let x = 1;
    if x == 1 {
        println("one");
    }
}
```

Chained assignment is the same error. Assign each binding on its own:

```lugha
fun main() {
    let mut a = 1;
    let mut b = 2;
    a = b = 0; // error: E0204
    println(a + b);
}
```

```lugha
fun main() {
    let mut a = 1;
    let mut b = 2;
    a = 0;
    b = 0;
    println(a + b);
}
```

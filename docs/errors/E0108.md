# E0108: Invalid character in a number

A number literal has a character that doesn't belong in it: letters glued
to the digits, a digit too big for the base (`9` in binary, `G` in hex),
or an upper-case prefix such as `0X`. Lugha reports the whole literal
instead of splitting it into a number and a name.

```lugha
fun main() {
    let flags = 0b102; // error: E0108
    println(flags);
}
```

Use only the digits of the base, here `0` and `1`:

```lugha
fun main() {
    let flags = 0b101;
    println(flags);
}
```

Prefixes are lower case:

```lugha
fun main() {
    let mask = 0XFF; // error: E0108
    println(mask);
}
```

```lugha
fun main() {
    let mask = 0xFF;
    println(mask);
}
```

# E0501: Assignment to an immutable binding

A value was assigned to a binding that isn't mutable. In Lugha a `let`
binding can't change unless it is declared `let mut`; parameters and loop
variables never can. Saying so up front makes it easy to see, when reading
a function, which names may change.

```lugha
fun main() {
    let total = 0;
    total = 5; // error: E0501
    println(total);
}
```

The same holds for changing part of a value: `xs[0] = 1`, `p.x = 2` and
`for x of mut xs` all need `xs` or `p` to be `let mut`.

Declare the binding mutable:

```lugha
fun main() {
    let mut total = 0;
    total = 5;
    println(total);
}
```

A parameter or a loop variable can't be made mutable. Copy it into a new
`let mut` binding and change that instead:

```lugha
fun countdown(n: i64) {
    let mut left = n;
    while left > 0 {
        println(left);
        left -= 1;
    }
}

fun main() {
    countdown(3);
}
```

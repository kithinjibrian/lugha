# E0410: No such field

A field was read, written or given in a struct literal that the type
doesn't have. The fields of a struct are exactly the ones its declaration
lists, and built-in types have only their documented fields, such as
`len` on strings and arrays. A typo in a field name is the usual cause.

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0, y: 2.0 };
    println(p.z); // error: E0410
}
```

Use a field the type declares, or add the field to the struct:

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0, y: 2.0 };
    println(p.y);
}
```

Built-in types have few fields. A string's length is `len`, not `size`:

```lugha
fun main() {
    let s = "hello";
    println(s.size); // error: E0410
}
```

```lugha
fun main() {
    let s = "hello";
    println(s.len);
}
```

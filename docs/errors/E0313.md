# E0313: An item, method or field not visible here

The code uses an item, method or field that its module doesn't make
visible here. Without a keyword an item is visible in its own package;
`private` keeps it inside its module, and only `public` items reach other
packages. This lets a module or library keep helpers and fields to itself
and change them later without breaking anyone who uses it. The standard
library is a package of its own, so only its `public` items are usable.

```lugha
import std.random;

fun main() {
    let r = random.seeded(7);
    println(r.s0); // error: E0313
}
```

Use what the module offers publicly instead:

```lugha
import std.random;

fun main() {
    let mut r = random.seeded(7);
    println(r.below(10) < 10);
}
```

For your own modules, mark the item (or field) `public` if other packages
should use it, or remove `private` if only your own package needs it. An
item reached through a re-export, such as `shapes.Vec2` when `shapes`
imported `Vec2`, is only visible if that import was written `public import`.

# E0202: Unclosed delimiter

A `(`, `[` or `{` was still open when the file ended. The error points at
the opening one, which is usually far from where the closing one went
missing, so look for the block or call that isn't closed.

```lugha
fun main() { // error: E0202
    if true {
        println("yes");

}
```

Add the missing `}`:

```lugha
fun main() {
    if true {
        println("yes");
    }
}
```

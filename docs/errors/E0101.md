# E0101: Unexpected character

The source holds a character that can't start any token. Lugha's names
are ASCII letters, digits and `_`, and its operators are a fixed set; a
character outside both, such as `#`, a backtick or `é`, means nothing
outside a string or a comment. Comments start with `//`, not `#`.

```lugha
fun main() {
    let x = 5; # the starting value // error: E0101
    println(x);
}
```

Write the comment with `//`:

```lugha
fun main() {
    let x = 5; // the starting value
    println(x);
}
```

A letter outside ASCII in a name is the same error. Spell the name in
ASCII; the letter can still appear in strings:

```lugha
fun main() {
    let café = "open"; // error: E0101
    println(café);
}
```

```lugha
fun main() {
    let cafe = "café open";
    println(cafe);
}
```

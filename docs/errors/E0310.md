# E0310: Method declared twice, or named like a field or variant

A type has two methods with the same name, or a method named like one of
its fields or variants. `p.x` has to mean one thing: if `Point` had both a
field `x` and a method `x`, `p.x` and `p.x()` would be too easy to mix up,
so Lugha keeps one name space per type. All the `impl` blocks of a type
count together.

```lugha
struct Point { x: i64, y: i64 }

impl Point {
    fun x(self): i64 = self.x; // error: E0310
}

fun main() {}
```

Fields are read directly, so a getter is rarely needed. If the method does
something more, name it for what it does:

```lugha
struct Point { x: i64, y: i64 }

impl Point {
    fun sum(self): i64 = self.x + self.y;
}

fun main() {
    let p = Point { x: 1, y: 2 };
    println(p.x);
    println(p.sum());
}
```

Two methods with one name are reported too, even in separate `impl`
blocks:

```lugha
struct Counter { n: i64 }

impl Counter {
    fun get(self): i64 = self.n;
}

impl Counter {
    fun get(self): i64 = self.n * 2; // error: E0310
}

fun main() {}
```

```lugha
struct Counter { n: i64 }

impl Counter {
    fun get(self): i64 = self.n;
    fun doubled(self): i64 = self.n * 2;
}

fun main() {
    let c = Counter { n: 3 };
    println(c.doubled());
}
```

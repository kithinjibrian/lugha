# E0503: Missing return

A function with a result type must produce a value on every path through
its body, either with `return` or with a final expression without a `;`.
This one has a path that reaches the end of the body with no value. The
check is simple on purpose: it doesn't try to prove that a path can't
happen, so even a `while true` loop counts as a way to the end. A `loop`
with no `break` leaving it never ends, so write `loop { … }` for a loop
whose only exit is a `return`.

```lugha
fun sign(n: i64): i64 { // error: E0503
    if n < 0 {
        return -1;
    }
}

fun main() {
    println(sign(5));
}
```

Give the remaining path a value:

```lugha
fun sign(n: i64): i64 {
    if n < 0 {
        return -1;
    }
    if n > 0 { 1 } else { 0 }
}

fun main() {
    println(sign(5));
}
```

A common slip is a `;` after the last expression, which turns the value
into a statement; the compiler points at it with "remove this semicolon".
And when a path really can't be reached, say so with `panic`:

```lugha
fun first_even(xs: i64[]): i64 {
    for x of xs {
        if x % 2 == 0 {
            return x;
        }
    }
    panic("no even number");
}

fun main() {
    println(first_even([3, 4, 5]));
}
```

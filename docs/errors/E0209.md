# E0209: A closure parameter that isn't a plain name

A closure's parameters are plain names, with an optional type: `fun(x)`
or `fun(x: i64)`. A closure has no receiver, so `self` can't be one, and
parameters are never `mut`.

```lugha
fun main() {
    let count_down = fun(mut n: i64): i64 { // error: E0209
        n -= 1;
        n
    };
    println(count_down(3));
}
```

Copy the parameter into a `let mut` binding and change that:

```lugha
fun main() {
    let count_down = fun(n: i64): i64 {
        let mut left = n;
        left -= 1;
        left
    };
    println(count_down(3));
}
```

# E0418: Wrong number of type arguments

A generic type was written with a different number of type arguments
than it declares, or with none at all where a type is required.
`Stack<T>` takes exactly one, so `Stack<i64, i64>` and a bare `Stack`
as a parameter type are both incomplete or ambiguous. Lugha infers type
arguments in expressions, but a written type must be spelled out in full.

```lugha
struct Stack<T> { items: T[] }

fun size(s: Stack<i64, i64>): i64 = s.items.len; // error: E0418

fun main() {
    println(size(Stack { items: [1, 2] }));
}
```

Give one type argument per type parameter:

```lugha
struct Stack<T> { items: T[] }

fun size(s: Stack<i64>): i64 = s.items.len;

fun main() {
    println(size(Stack { items: [1, 2] }));
}
```

A bare generic type needs its argument too, or a type parameter of the
function's own:

```lugha
struct Stack<T> { items: T[] }

fun size(s: Stack): i64 = s.items.len; // error: E0418

fun main() {
    println(size(Stack { items: [1, 2] }));
}
```

```lugha
struct Stack<T> { items: T[] }

fun size<T>(s: Stack<T>): i64 = s.items.len;

fun main() {
    println(size(Stack { items: [1, 2] }));
}
```

# E0308: Field declared twice

A struct declares two fields with the same name. `p.x` must name one field,
so each field name may appear once in a struct.

```lugha
struct Point { x: i64, y: i64, x: f64 } // error: E0308

fun main() {}
```

Remove the extra field, or give it a name of its own:

```lugha
struct Point { x: i64, y: i64, weight: f64 }

fun main() {
    let p = Point { x: 1, y: 2, weight: 0.5 };
    println(p.x);
}
```

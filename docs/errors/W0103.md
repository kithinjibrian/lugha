# W0103: Unused `match` binding (warning)

In a pattern, a name that isn't a variant of the value's type is a new
binding that matches anything. So a misspelled variant, `Emtpy` for
`Empty`, silently becomes a catch-all instead of a test. When such a
binding is never used in the arm, Lugha warns, since it is almost always a
typo.

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    Some(Full(n)) => n,
    Some(Emtpy) => 0, // warning: W0103
    None => 0,
};

fun main() {
    println(count(Some(Cell.Full(3))));
}
```

Spell the variant correctly:

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    Some(Full(n)) => n,
    Some(Empty) => 0,
    None => 0,
};

fun main() {
    println(count(Some(Cell.Full(3))));
}
```

If you did mean to match anything there, write `_`, which says so:

```lugha
enum Cell { Empty, Full(i64) }

fun count(c: Option<Cell>): i64 = match c {
    Some(Full(n)) => n,
    Some(_) => 0,
    None => 0,
};

fun main() {
    println(count(Some(Cell.Full(3))));
}
```

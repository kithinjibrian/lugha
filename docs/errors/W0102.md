# W0102: Unreachable `match` arm (warning)

`match` tries its arms from top to bottom and runs the first that fits. An
arm whose values are all taken by earlier arms can never run, for example
any arm after `_`, or a variant already covered above. The program still
compiles, but the arm is dead code and usually means the arms are in the
wrong order.

```lugha
fun main() {
    let n = 1;
    match n {
        0 => println("zero"),
        _ => println("something else"),
        1 => println("one"), // warning: W0102
    }
}
```

Put the specific arms before the catch-all:

```lugha
fun main() {
    let n = 1;
    match n {
        0 => println("zero"),
        1 => println("one"),
        _ => println("something else"),
    }
}
```

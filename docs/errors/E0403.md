# E0403: Type mismatch

A value of one type was used where another is expected: assigned to an
annotated binding, passed as an argument, returned from a function, or
given as one branch of an `if` whose other branch has a different type.
Lugha never converts between types on its own, so the types have to
match exactly.

```lugha
fun main() {
    let ready = true;
    let n: i32 = ready; // error: E0403
    println(n);
}
```

Convert the value explicitly, in the way you mean:

```lugha
fun main() {
    let ready = true;
    let n: i32 = if ready { 1 } else { 0 };
    println(n);
}
```

Both branches of an `if` used as a value must have the same type:

```lugha
fun label(n: i64): string = if n > 0 { "positive" } else { n }; // error: E0403

fun main() {
    println(label(3));
}
```

Make the branches agree:

```lugha
fun label(n: i64): string = if n > 0 { "positive" } else { "not positive" };

fun main() {
    println(label(3));
}
```

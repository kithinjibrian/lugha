# E0441: A float as a map key or set value

A map's keys and a set's values are found by hashing and `==`. A float
can't be one: `NaN != NaN`, so a `NaN` key could never be found again,
and `0.0 == -0.0` would make two different bit patterns one key. The rule
covers floats anywhere inside the key's type: a tuple, struct, enum,
array or `Option` holding one.

```lugha
fun main() {
    let prices = #{1.5: "cheap", 9.5: "dear"}; // error: E0441
}
```

Key by an integer instead, such as an amount in cents, or keep the floats
as values:

```lugha
fun main() {
    let prices = #{150: "cheap", 950: "dear"};
    let by_name = #{"cheap": 1.5, "dear": 9.5};
    println(prices[150]);
    println(by_name["dear"]);
}
```

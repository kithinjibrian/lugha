# E0317: Retired in v8

This code is never reported and will never be reused for anything else.

Before v8, `public` existed but meant nothing yet, because there were no
packages, so writing it was E0317. Version 8 gave items three visibility
levels: `private` (its module only), no keyword (its package) and `public`
(any package). Since then `public` is valid wherever a visibility can be
written, and using something that isn't visible is E0313 instead.

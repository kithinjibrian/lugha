# E0455: A `return`, `?`, `break` or `continue` leaving a deferred statement

A `defer` statement runs while its block is already being left: at its
end, or by a `return`, `?`, `break` or `continue`. So it can't leave the
block itself: a `return`, `?`, `break` or `continue` inside it that would
jump out of it is an error.

```lugha
fun load(): Result<i64, string> = Err("no");

fun run(): Result<i64, string> {
    defer {
        let n = load()?; // error: E0455
    }
    Ok(1)
}

fun main() {
    println(run());
}
```

Handle the case inside the deferred statement instead:

```lugha
fun load(): Result<i64, string> = Err("no");

fun run(): Result<i64, string> {
    defer {
        match load() {
            Ok(n) => println(n),
            Err(e) => eprintln("cleanup failed: {e}"),
        }
    }
    Ok(1)
}

fun main() {
    println(run());
}
```

A loop written inside the deferred statement may still use `break` and
`continue`, and a closure inside it may `return`: they don't leave it.

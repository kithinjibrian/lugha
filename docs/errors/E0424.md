# E0424: `?` where it can't return

`e?` unwraps an `Option` or a `Result`, and on `None` or `Err` returns it
from the enclosing function at once. That only works when the function
returns the same kind of thing: an `Option` for an `Option`, a `Result`
with a matching (or convertible) error type for a `Result`. `main` returns
nothing, so `?` can't be used there, and `?` on a plain value like an `i64`
has nothing to unwrap.

```lugha
fun main() {
    let n = parse_i64("42")?; // error: E0424
    println(n);
}
```

In `main`, handle the missing case yourself:

```lugha
fun main() {
    match parse_i64("42") {
        Some(n) => println(n),
        None => println("not a number"),
    }
}
```

Or move the work into a function that returns an `Option`, where `?` can
pass the `None` on:

```lugha
fun double(s: string): Option<i64> {
    let n = parse_i64(s)?;
    Some(n * 2)
}

fun main() {
    println(double("21").unwrap_or(0));
}
```

# E0111: Bad interpolation in a string

Braces in a string mark interpolation: `"{x}"` puts the value of `x` into
the text. So a `{` must have a matching `}` with an expression between
them, and a lone `}` is an error too. To write a brace itself, double it:
`{{` or `}}`.

```lugha
fun main() {
    let name = "Ada";
    // error: E0111
    println("hello, {name");
}
```

Close the hole:

```lugha
fun main() {
    let name = "Ada";
    println("hello, {name}");
}
```

Braces meant as text are doubled:

```lugha
fun main() {
    // error: E0111
    println("a set: {}");
}
```

```lugha
fun main() {
    println("a set: {{}}");
}
```

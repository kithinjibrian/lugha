# E0112: A bad `char` literal

A `char` literal between single quotes holds exactly one character or one
escape: `'a'`, `'\n'`, `'\u{1F600}'`. It's an error when it is empty,
holds more than one character, uses an unknown escape, names a code point
that isn't a Unicode scalar value (`'\u{D800}'`, `'\u{110000}'`), or is
never closed.

```lugha
fun main() {
    let greeting = 'hi'; // error: E0112
    println(greeting);
}
```

Text longer than one character is a string, in double quotes:

```lugha
fun main() {
    let greeting = "hi";
    println(greeting);
}
```

An empty literal has no character to hold. Write the one you mean, such
as a space:

```lugha
fun main() {
    let gap = ''; // error: E0112
    println(gap);
}
```

```lugha
fun main() {
    let gap = ' ';
    println(gap);
}
```

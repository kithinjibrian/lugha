# E0311: A local named like a type or an imported module

A local binding, parameter or pattern binding has the name of a type or of
an imported module. In Lugha `Point.origin()` or `shapes.area(c)` starts
with a type or module name, so a local with that name would make such code
ambiguous. Lugha rules it out instead of letting one silently hide the
other.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let Point = Point { x: 1, y: 2 }; // error: E0311
}
```

Name the local differently; lower-case names are the convention for values:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let point = Point { x: 1, y: 2 };
    println(point.x);
}
```

The same goes for an imported module's name:

```lugha
import std.math;

fun main() {
    let math = 3; // error: E0311
}
```

```lugha
import std.math;

fun main() {
    let score = 3;
    println(math.max(score, 5));
}
```

# E0507: Assignment to the array being iterated

While `for x of xs` runs, `xs` can't change: not by assignment to it or its
elements, not by `push`, `pop` or `clear`, not through a `mut self` method
or `swap`. Changing the array under the loop would leave it unclear which
elements the loop still visits. The same goes for calling `it.next()` on an
iterator inside `for n of mut it`.

```lugha
fun main() {
    let mut xs = [1, 2, 3];
    for x of xs {
        xs[0] = x; // error: E0507
    }
    println(xs);
}
```

To change the elements as you go, loop with `mut`, which gives a changeable
binding for each element:

```lugha
fun main() {
    let mut xs = [1, 2, 3];
    for x of mut xs {
        x *= 10;
    }
    println(xs);
}
```

Or loop over the indices and change the array by index:

```lugha
fun main() {
    let mut xs = [1, 2, 3];
    for i in 0..xs.len {
        xs[0] = xs[i];
    }
    println(xs);
}
```

# E0420: Generic instantiation too deep

Lugha compiles a separate copy of a generic function for every type it is
used with. When a generic function calls itself with a bigger type each
time, such as `T`, then `T[]`, then `T[][]`, there is no end to the copies
it would need, so the compiler stops and reports this instead of running
forever. A generic struct whose fields nest itself the same way is reported
for the same reason.

```lugha
fun nest<T>(x: T, depth: i64) {
    if depth > 0 {
        nest([x], depth - 1); // error: E0420
    }
}

fun main() {
    nest(1, 3);
}
```

Recursion is fine as long as each call uses the same type arguments. Keep
the type fixed and carry the growing part in a value instead:

```lugha
fun nest<T>(x: T, depth: i64): T[] {
    let mut out: T[] = [];
    let mut left = depth;
    while left > 0 {
        out.push(x);
        left -= 1;
    }
    out
}

fun main() {
    println(nest(1, 3));
}
```

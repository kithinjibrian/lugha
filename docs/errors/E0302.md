# E0302: Name defined more than once, or a function named like an intrinsic

Two top-level items in one file have the same name, or a function takes the
name of a built-in such as `println`. Every name at the top of a file must
mean one thing, so a call like `area(c)` never has to guess which `area`
was meant. Functions, structs, enums, interfaces and the names brought in
by `import m { … }` all share this space.

```lugha
fun area(w: i64, h: i64): i64 = w * h;
fun area(side: i64): i64 = side * side; // error: E0302

fun main() {
    println(area(2, 3));
}
```

Give each function its own name (Lugha has no overloading by parameter
types):

```lugha
fun area(w: i64, h: i64): i64 = w * h;
fun square_area(side: i64): i64 = side * side;

fun main() {
    println(area(2, 3));
    println(square_area(4));
}
```

The built-in functions can't be redefined either:

```lugha
fun println(s: string) {} // error: E0302

fun main() {}
```

Pick a different name for your own version:

```lugha
fun shout(s: string) {
    println(s + "!");
}

fun main() {
    shout("hello");
}
```

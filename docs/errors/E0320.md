# E0320: A package name that is also a local folder or file

A name is both a package and a module of the program's own folder. The
program's own modules have no package prefix, so with package `geo` listed
in `lugha.toml` and a folder `geo/` beside `main.la`, `import geo.shapes;`
could mean either `geo/shapes.la` or the package's `shapes.la`. Lugha
reports the clash instead of picking one. `std` is reserved for the
standard library in the same way, so a `std/` folder or `std.la` file next
to a module that imports `std.math` is E0320 too.

These examples need several files, so they aren't checked as one program:

```text
# lugha.toml
[packages]
geo = "libs/geo" # error: E0320

# files
main.la
geo/shapes.la
libs/geo/shapes.la
```

Rename one of them: the local folder (`geo/` to `shapes/`, and its imports
to `import shapes.…;`), or the package's key in `lugha.toml`. If the
package declares its own `name`, rename the folder, since the key must
match that name (E0327).

```text
main.la      // import std.math;
std.la       // error: E0320
```

Here rename `std.la`, for example to `stats.la`.

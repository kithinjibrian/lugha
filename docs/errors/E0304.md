# E0304: `main` with the wrong signature, generic, or outside the main file

`main` must be written `fun main()` or `fun main(): i32`, with no
parameters and no type parameters, and only in the main file. The program
is started from C, which calls it with nothing and reads back at most an
exit code, so any other shape couldn't be called. A `main` inside an
imported module is reported too: there is only one entry point.

```lugha
fun main(args: string[]) { // error: E0304
    println(args.len);
}
```

Command-line arguments come from the built-in `args()` instead:

```lugha
fun main() {
    let all = args();
    println(all.len);
}
```

To choose the exit code, return an `i32`, not another type:

```lugha
fun main(): i64 { // error: E0304
    1
}
```

```lugha
fun main(): i32 {
    1
}
```

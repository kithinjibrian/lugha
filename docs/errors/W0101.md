# W0101: Unreachable code (warning)

Statements after a `return`, `break` or `continue` in the same block can
never run. That is usually a leftover from editing, or a sign that the jump
is in the wrong place. The program still compiles; the warning is reported
once per block, at the first unreachable statement.

```lugha
fun main() {
    println("start");
    return;
    println("never printed"); // warning: W0101
}
```

Remove the dead statements, or move the jump to where it was meant to be:

```lugha
fun main() {
    println("start");
    println("now printed");
}
```

# E0448: `include_str` of a file that isn't UTF-8

`include_str(path)` gives a file's contents as a `string`, and every
`string` holds valid UTF-8, so the file must be UTF-8 text. The message
gives the offset and value of the first byte that isn't:

```text
error[E0448]: `logo.png` is not UTF-8: byte 0 is 0x89
 --> main.la:1:34
  |
1 | const LOGO: string = include_str("logo.png");
  |                                  ^^^^^^^^^^
```

Binary data is `include_bytes`, a `u8[]`; `string_from_utf8` turns bytes
into a string at run time, where a failure is a value:

```lugha
const LOGO: u8[] = include_bytes("main.la");

fun main() {
    match string_from_utf8(LOGO) {
        Ok(text) => println(text.len > 0),
        Err(e) => println(e),
    }
}
```

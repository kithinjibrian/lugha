# E0427: An interface that uses `Self` used as a type

In an interface, `Self` means "the type that satisfies it". In
`fun less(self, other: Self): bool`, an `Age` compares with another `Age`.
An interface value can hold any satisfying type, so two of them might hold
an `Age` and something else, and `less` couldn't be called between them.
Such an interface can be a bound but not a type.

```lugha
interface Ordered {
    fun less(self, other: Self): bool;
}

struct Age { years: i64 }

impl Age {
    fun less(self, other: Self): bool = self.years < other.years;
}

fun main() {
    let xs: Ordered[] = [Age { years: 3 }, Age { years: 1 }]; // error: E0427
}
```

Use it as a bound, so every element has the same concrete type:

```lugha
interface Ordered {
    fun less(self, other: Self): bool;
}

struct Age { years: i64 }

impl Age {
    fun less(self, other: Self): bool = self.years < other.years;
}

fun smallest<T: Ordered>(xs: T[]): T {
    let mut best = xs[0];
    for x of xs {
        if x.less(best) {
            best = x;
        }
    }
    best
}

fun main() {
    let xs = [Age { years: 3 }, Age { years: 1 }];
    println(smallest(xs).years);
}
```

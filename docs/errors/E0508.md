# E0508: Argument aliases a `mut self` receiver

A `mut self` method may change its receiver while it runs. If one of its
arguments is that same value, or a part of it, the method would be reading
something it is also changing, and the result would depend on the order of
its steps. Lugha rules this out, so a method can always treat its arguments
as unaffected by what it does to `self`.

```lugha
struct Vec2 { x: i64, y: i64 }

impl Vec2 {
    fun add(mut self, other: Vec2) {
        self.x += other.x;
        self.y += other.y;
    }
}

fun main() {
    let mut v = Vec2 { x: 1, y: 2 };
    v.add(v); // error: E0508
    println(v.x);
}
```

Copy the argument into its own binding first:

```lugha
struct Vec2 { x: i64, y: i64 }

impl Vec2 {
    fun add(mut self, other: Vec2) {
        self.x += other.x;
        self.y += other.y;
    }
}

fun main() {
    let mut v = Vec2 { x: 1, y: 2 };
    let w = v;
    v.add(w);
    println(v.x);
}
```

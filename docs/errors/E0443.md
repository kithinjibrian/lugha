# E0443: `out` missing or misplaced in a call

An extern's `out` parameter is a pointer C writes through, and the call
says so: `out place`, with a place to store what C wrote. This error is a
call that leaves `out` off for such a parameter, or writes `out` for one
that isn't `out` (or in a call of anything but an extern).

```text
// main.la, with get_fuel in a C file linked through [link]
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(fuel); // error: E0443
}
```

Write `out` before the place:

```text
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(out fuel);
    println(fuel);
}
```

The examples call C, so they aren't checked as programs here.

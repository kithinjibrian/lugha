# E0443: `out` missing or misplaced in a call

An extern's `out`, `ptr` and `mut` parameters are pointers, and the call
says so with the same word: `out place` (C writes it), `ptr e` (C reads a
copy) or `mut place` (C reads and changes it). This error is a call that
leaves the word off for such a parameter, writes a different one, writes
one for a parameter that has none, or writes one in a call of anything but
an extern.

```text
// main.la, with get_fuel in a C file linked through [link]
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(fuel); // error: E0443
}
```

Write `out` before the place:

```text
extern fun get_fuel(out fuel: u64): bool;

fun main() {
    let mut fuel: u64 = 0;
    get_fuel(out fuel);
    println(fuel);
}
```

The examples call C, so they aren't checked as programs here.

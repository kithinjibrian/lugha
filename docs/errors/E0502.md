# E0502: Assignment to something that isn't a place

The left side of `=`, `+=` and the like must be a place: a variable, a
field, an element, or a chain of those such as `shapes[0].r`. A computed
value like `a + b` or a function call's result has nowhere to store
anything, so assigning to it would do nothing.

```lugha
fun main() {
    let mut a = 1;
    let b = 2;
    (a + b) = 3; // error: E0502
    println(a);
}
```

`for x of mut e` needs a place too, since it writes the elements back:
`for x of mut [1, 2]` has nowhere to write them.

Assign to the variable you mean to change:

```lugha
fun main() {
    let mut a = 1;
    let b = 2;
    a = 3 - b;
    println(a);
}
```

An element read through a type's own `index` method is a copy. Assigning
inside it works (`r[0][0] = 2` reads the row, changes the copy and hands it
back with `set_index`), but `swap` and `for x of mut` can't hand a copy
back, so through `index` they are E0502:

```lugha
struct Rows { rows: i64[][] }

impl Rows {
    fun index(self, i: i64): i64[] = self.rows[i];
    fun set_index(mut self, i: i64, v: i64[]) { self.rows[i] = v; }
}

fun main() {
    let mut r = Rows { rows: [[1]] };
    for x of mut r[0] { // error: E0502
        x = 2;
    }
}
```

Change a copy, then write it back with `set_index`:

```lugha
struct Rows { rows: i64[][] }

impl Rows {
    fun index(self, i: i64): i64[] = self.rows[i];
    fun set_index(mut self, i: i64, v: i64[]) { self.rows[i] = v; }
}

fun main() {
    let mut r = Rows { rows: [[1]] };
    let mut row = r[0];
    for x of mut row {
        x = 2;
    }
    r[0] = row;
    println(r[0]);
}
```

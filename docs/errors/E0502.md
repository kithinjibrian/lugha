# E0502: Assignment to something that isn't a place

The left side of `=`, `+=` and the like must be a place: a variable, a
field, an element, or a chain of those such as `shapes[0].r`. A computed
value like `a + b` or a function call's result has nowhere to store
anything, so assigning to it would do nothing.

```lugha
fun main() {
    let mut a = 1;
    let b = 2;
    (a + b) = 3; // error: E0502
    println(a);
}
```

`for x of mut e` needs a place too, since it writes the elements back:
`for x of mut [1, 2]` has nowhere to write them.

Assign to the variable you mean to change:

```lugha
fun main() {
    let mut a = 1;
    let b = 2;
    a = 3 - b;
    println(a);
}
```

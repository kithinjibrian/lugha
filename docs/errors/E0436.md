# E0436: A function with captures passed to a callback without `data`

A callback declared without `data`, such as `qsort`'s comparator, is a
bare C function pointer: when C calls it, it passes only the callback's
own arguments. A closure's captured variables live in an environment
that has to travel with the code, and here there is nowhere for it to
go. So such a callback takes only a function's name, or a closure that
captures nothing. A callback declared with `data` takes any function,
since the closure travels as the user data.

```lugha
extern fun sort_by(n: i64, cmp: fun(i64, i64): i32);

fun main() {
    let flip: i32 = -1;
    sort_by(3, fun(a: i64, b: i64): i32 = if a < b { flip } else { 1 }); // error: E0436
}
```

Use a named function, or a closure that uses only its parameters:

```lugha
extern fun sort_by(n: i64, cmp: fun(i64, i64): i32);

fun descending(a: i64, b: i64): i32 = if a > b { -1 } else if a < b { 1 } else { 0 };

fun main() {
    sort_by(3, descending);
    sort_by(3, fun(a: i64, b: i64): i32 = if a < b { -1 } else { 1 });
}
```

If the C function takes user data, declare that with `data` (see
E0435), and any closure can be passed.

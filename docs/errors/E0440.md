# E0440: `..base` of another type

A struct literal may end with `..base`: every field it doesn't write is
copied from `base`. That only makes sense when `base` is the same struct,
with the same type arguments, so lughac never guesses which fields of
another type to take, even when the names line up.

```lugha
struct Point { x: f64, y: f64 }
struct Size { x: f64, y: f64 }

fun main() {
    let s = Size { x: 2.0, y: 3.0 };
    let p = Point { x: 1.0, ..s }; // error: E0440
}
```

Use a value of the literal's own type as the base, or write the fields:

```lugha
struct Point { x: f64, y: f64 }
struct Size { x: f64, y: f64 }

fun main() {
    let s = Size { x: 2.0, y: 3.0 };
    let origin = Point { x: 0.0, y: 0.0 };
    let a = Point { x: 1.0, ..origin };
    let b = Point { x: 1.0, y: s.y };
    println(a.y + b.y);
}
```

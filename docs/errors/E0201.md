# E0201: Unexpected token

The parser found a token where it doesn't fit the grammar. The message
says what it expected instead. The most common cause is a missing `;`:
every statement in Lugha ends with one, so a second statement on the same
line runs straight into the first.

```lugha
fun main() {
    let x = 1
    let y = 2; // error: E0201
    println(x + y);
}
```

End the statement with `;`:

```lugha
fun main() {
    let x = 1;
    let y = 2;
    println(x + y);
}
```

Another is a statement outside any function. Only declarations (`fun`,
`struct`, `enum`, `impl`, `import` and the like) go at the top level:

```lugha
let limit = 10; // error: E0201

fun main() {
    println(limit);
}
```

Move the binding into a function, or make it a function that returns it:

```lugha
fun limit(): i64 = 10;

fun main() {
    println(limit());
}
```

# E0437: A malformed `extern struct`

An `extern struct` promises C's layout, so lughac can pass it to C by
value exactly as a C compiler would. That only works for fields C can
hold the same way: numbers, `bool`, `char`, handles declared with
`extern type`, and other extern structs. A string, an array, a plain
struct, an enum, an `Option` or a function has Lugha's own layout, which
C can't read. C has no generics and no empty structs either.

```lugha
extern struct Label { text: string, size: f32 } // error: E0437

fun main() {}
```

Keep the C-shaped part in the `extern struct`, and the rest in an
ordinary struct around it:

```lugha
extern struct Font { size: f32, bold: bool }

struct Label {
    text: string,
    font: Font,
}

fun main() {
    let l = Label { text: "hi", font: Font { size: 12.0, bold: false } };
    println(l.font.size);
}
```

A text field in a C struct is a `char *`, which Lugha can't hold by value
yet: declare that struct as a handle (`extern type`) and read it through
C functions.

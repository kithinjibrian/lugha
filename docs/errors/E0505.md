# E0505: Block-like statement with a discarded value

An `if`, `match` or block written as a statement, with more statements
after it, has its value thrown away. If its branches produce a value, that
was probably meant to go somewhere, such as into a `let` or to be the
function's result, so Lugha reports it instead of dropping it silently.

```lugha
fun main() {
    let big = true;
    if big { 100 } else { 1 } // error: E0505
    println("done");
}
```

Use the value:

```lugha
fun main() {
    let big = true;
    let size = if big { 100 } else { 1 };
    println(size);
    println("done");
}
```

Or, if the branches are only there for what they do, end them with `;` so
they have no value:

```lugha
fun main() {
    let big = true;
    if big { println("big"); } else { println("small"); }
    println("done");
}
```

# E0106: Number is missing digits

A number literal stops before its digits: a prefix such as `0x` or `0b`
with nothing after it, or a float exponent `e` (or `e+`, `e-`) with no
digits. Lugha doesn't guess a zero, since the number was most likely cut
short by mistake.

```lugha
fun main() {
    let mask = 0x; // error: E0106
    println(mask);
}
```

Write the digits:

```lugha
fun main() {
    let mask = 0xFF;
    println(mask);
}
```

An exponent needs digits too:

```lugha
fun main() {
    let size = 2.0e; // error: E0106
    println(size);
}
```

```lugha
fun main() {
    let size = 2.0e3;
    println(size);
}
```

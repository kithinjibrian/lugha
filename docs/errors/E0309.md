# E0309: Variant declared twice

An enum declares two variants with the same name. `Shape.Circle` and a
`match` arm on `Circle` must each mean one variant, so variant names are
unique within their enum.

```lugha
enum Shape { Circle, Square, Circle } // error: E0309

fun main() {}
```

Remove the repeated variant, or rename it:

```lugha
enum Shape { Circle, Square, Triangle }

fun main() {
    let s = Shape.Circle;
    match s {
        Circle => println("round"),
        _ => println("corners"),
    }
}
```

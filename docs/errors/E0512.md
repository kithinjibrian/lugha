# E0512: Unknown label

A label names an enclosing loop: `outer: for … { … }`. `continue name;`,
and `break name;` inside a closure, must name a loop around them, and none
has this name. Labels don't reach into closures, since a closure's body is
its own function.

```lugha
fun main() {
    rows: for r in 0..3 {
        for c in 0..3 {
            if c > r {
                continue row; // error: E0512
            }
            println("{r}{c}");
        }
    }
}
```

Use the label the loop has:

```lugha
fun main() {
    rows: for r in 0..3 {
        for c in 0..3 {
            if c > r {
                continue rows;
            }
            println("{r}{c}");
        }
    }
}
```

After `break`, a name that no enclosing loop has is read as a value
(`break x;` breaks with `x`), so a misspelt label there is E0301 instead.

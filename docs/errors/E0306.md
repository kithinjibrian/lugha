# E0306: Reserved extern name, or one C function declared with two signatures

An `extern fun` names a C function that Lugha can't let you declare. Names
starting with `lugha_` belong to the compiler and its runtime, so declaring
one could clash with, or call into, their internals. The same code is also
reported when one C function is declared in two modules with different
signatures: it is one symbol in the program, so it can have only one type.

```lugha
extern fun lugha_rt_alloc(size: i64): i64; // error: E0306

fun main() {}
```

Declare only C functions of your own or of a C library, under their real
names:

```lugha
extern fun abs(x: i32): i32;

fun main() {
    println(abs(-4));
}
```

If two modules declare the same C function, give both declarations exactly
the same parameter and return types, or declare it once in a module the
others import.

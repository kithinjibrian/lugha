# E0316: Bad type parameter name

A type parameter's name can't be used: it repeats another parameter of the
same declaration, or it is already the name of a type, such as a struct or
`Self`. Inside `fun f<T>`, `T` must mean only that parameter, so it may not
hide a real type.

```lugha
fun pair<T, T>(a: T, b: T) {} // error: E0316

fun main() {}
```

Give each parameter its own name, or use one parameter for both:

```lugha
fun pair<A, B>(a: A, b: B) {
    println(a);
    println(b);
}

fun main() {
    pair(1, "one");
}
```

A parameter named like a struct is reported too:

```lugha
struct Point { x: i64 }

fun show<Point>(p: Point) {} // error: E0316

fun main() {}
```

```lugha
struct Point { x: i64 }

fun show<T>(p: T) {
    println(p);
}

fun main() {
    show(Point { x: 1 }.x);
}
```

# E0406: Not a function, or something that can't be a value

Either something that isn't a function was called, or something that
can't be used as a value was used as one. Only functions and function
values can be called. And while a plain function can be stored in a
binding, a method, a built-in such as `println` and an `extern` function
can't: wrap them in a closure instead.

```lugha
fun main() {
    let step = 2;
    println(step(1)); // error: E0406
}
```

Call a function, or use the value directly:

```lugha
fun step(n: i64): i64 = n + 2;

fun main() {
    println(step(1));
}
```

A built-in used as a value is the other common cause:

```lugha
fun main() {
    let show = println; // error: E0406
    show(1);
}
```

Wrap it in a closure:

```lugha
fun main() {
    let show = fun(n: i64) { println(n); };
    show(1);
}
```

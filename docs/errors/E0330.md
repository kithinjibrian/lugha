# E0330: A `[link]` C file that doesn't compile

A C file listed under `c` in a `[link]` table didn't compile. lughac
compiles each such file with the system C compiler, `cc -c`, adding only
its own package's `include` folders and `pkg-config --cflags`, and links
the result into the program. The help shows what the C compiler said.

The example is a manifest and a C file, so it isn't checked as one
program:

```text
# lugha.toml
[link]
c = ["shim.c"] # error: E0330

/* shim.c */
long twice(long x) { return 2 * x }
```

Fix the C file as the compiler's message says, here the missing `;`
after `2 * x`. If it can't find a header, add the header's folder to
`include` (relative to the package), or the library's name to
`pkg-config`. `lughac check` doesn't compile C files, so this error only
appears when building, running or testing.

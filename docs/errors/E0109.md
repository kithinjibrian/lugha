# E0109: Float literal out of range

A float literal is too large for `f64`, whose biggest finite value is about
`1.8e308`. Rather than turning it into infinity, Lugha rejects it, since a
literal like that is almost always a typo in the exponent.

```lugha
fun main() {
    let huge = 1.0e999; // error: E0109
    println(huge);
}
```

Use an exponent within range:

```lugha
fun main() {
    let huge = 1.0e99;
    println(huge);
}
```

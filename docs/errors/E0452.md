# E0452: A derive block in the wrong module, or overlapping another

Only an interface's own module says how types meet it, so a `derive` block
must be written in the module that declares the interface. And each type
gets its items from one block: two blocks of one interface that could both
cover a type are an error.

```lugha
interface Show {
    fun show(self): string;
}

derive<T: Show> Show for Option<T> {
    fun show(self): string = "maybe";
}

derive Show for Option<i64> { // error: E0452
    fun show(self): string = "maybe a number";
}

fun main() {}
```

Keep one block per type. A struct or enum that needs something different
from its block writes its own method instead, which replaces that item:

```lugha
interface Show {
    fun show(self): string;
}

derive Show for struct {
    fun show(self): string = "a struct";
}

fun show<T: Show>(x: T): string = x.show();

struct Secret {
    code: i64,
}

impl Secret {
    fun show(self): string = "****";
}

fun main() {
    println(show(Secret { code: 42 }));
}
```

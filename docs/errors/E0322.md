# E0322: A manifest path that doesn't exist

A path in `lugha.toml` names a folder that isn't there: a package's `path`
under `[packages]`, the `source` folder under `[package]`, or (v16) a
`paths` or `include` folder or a `c` file under `[link]`. Paths are
relative to the folder holding that `lugha.toml`. lughac reports the
listing itself, so the mistake is shown where it was made rather than at
the first import that needs the package.

The example is a manifest and a set of folders, so it isn't checked as one
program:

```text
# lugha.toml, next to main.la and libs/geo/
[packages]
geo = "libs/goe" # error: E0322
```

Correct the path so it names the package's folder relative to the
manifest, here `geo = "libs/geo"`, or create the folder. For `source`, the
folder is inside the package: `source = "src"` needs a `src/` folder next
to that package's `lugha.toml`. Under `[link]`, `c = ["shim/colors.c"]`
needs that file, relative to the same manifest.

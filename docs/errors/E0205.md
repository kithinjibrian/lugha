# E0205: Struct literal in a condition without parentheses

In the condition of `if`, `while`, `match` or `for`, a `{` starts the
block. So a struct literal such as `Point { x: 0, y: 0 }` there would be
read as the name `Point` followed by the body, and Lugha asks for
parentheses to make it clear.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 0, y: 0 };
    if p == Point { x: 0, y: 0 } { // error: E0205
        println("origin");
    }
}
```

Put the literal in parentheses:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 0, y: 0 };
    if p == (Point { x: 0, y: 0 }) {
        println("origin");
    }
}
```

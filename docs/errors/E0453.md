# E0453: A field intrinsic used wrongly

Inside a derive block, `derive.fields`, `derive.build`, `derive.variant`,
`derive.variants` and `derive.build_variant` reach the fields of whatever
struct, tuple or enum the block is used for. `fields` and `build` work in
`for struct` and `for tuple` blocks, the other three in `for enum` blocks,
and none of them outside a block. The function they call once per field
must be of the same module and generic over one `F` with the block's
interface. Inside a block a local can't be named `derive`.

```lugha
interface Count {
    fun count(self): i64;
}

derive Count for i64 {
    fun count(self): i64 = 1;
}

derive Count for enum {
    fun count(self): i64 = derive.fields(self, (), one).len; // error: E0453
}

fun one<F: Count>(c: (), name: string, x: F): i64 = x.count();

fun main() {}
```

An enum's block reads the payloads of the variant at hand:

```lugha
interface Count {
    fun count(self): i64;
}

derive Count for i64 {
    fun count(self): i64 = 1;
}

derive Count for enum {
    fun count(self): i64 {
        let (name, parts) = derive.variant(self, (), one);
        parts.len
    }
}

fun one<F: Count>(c: (), name: string, x: F): i64 = x.count();

fun main() {}
```

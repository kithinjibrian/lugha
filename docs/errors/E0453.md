# E0453: A field intrinsic used wrongly

Inside a derive block, `derive.fields`, `derive.build`, `derive.variant`,
`derive.variants`, `derive.build_variant`, `derive.fold`, `derive.index`
and `derive.address` reach the parts of whatever struct, tuple, enum or
handle the block is used for. `fields` and `build` work in `for struct`
and `for tuple` blocks; `variant`, `variants`, `build_variant` and `index`
in `for enum` blocks; `fold` in all three; `address` in `for handle`
blocks; and none of them outside a block. The function they call once per field
must be of the same module and generic over one `F` with the block's
interface. Inside a block a local can't be named `derive`.

```lugha
interface Count {
    fun count(self): i64;
}

derive Count for i64 {
    fun count(self): i64 = 1;
}

derive Count for enum {
    fun count(self): i64 = derive.fields(self, (), one).len; // error: E0453
}

fun one<F: Count>(c: (), name: string, x: F): i64 = x.count();

fun main() {}
```

An enum's block reads the payloads of the variant at hand:

```lugha
interface Count {
    fun count(self): i64;
}

derive Count for i64 {
    fun count(self): i64 = 1;
}

derive Count for enum {
    fun count(self): i64 {
        let (name, parts) = derive.variant(self, (), one);
        parts.len
    }
}

fun one<F: Count>(c: (), name: string, x: F): i64 = x.count();

fun main() {}
```

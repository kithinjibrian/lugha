# E0433: A pattern that must match every value but might not

Patterns in a plain `let` and in `for (a, b) of …` have no second branch:
if the value doesn't fit, there's nothing to run instead. So they must be
irrefutable, matching every value of their type, like a name, `_` or a
tuple of those. A pattern such as `Some(n)` or `(1, x)` can fail.

```lugha
fun main() {
    let o = parse_i64("42");
    let Some(n) = o; // error: E0433
    println(n);
}
```

Add an `else` that leaves when the pattern doesn't match:

```lugha
fun main() {
    let o = parse_i64("42");
    let Some(n) = o else {
        println("not a number");
        return;
    };
    println(n);
}
```

Or use `if let` or `match` to handle both cases:

```lugha
fun main() {
    if let Some(n) = parse_i64("42") {
        println(n);
    } else {
        println("not a number");
    }
}
```

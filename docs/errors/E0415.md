# E0415: No such variant or method

A variant was named that the enum doesn't declare, or a method was called
that the value's type doesn't have. Variants come from the enum's
declaration and methods from its `impl` blocks, its interfaces' default
methods, and the built-in methods of the type. Typos are the usual cause;
the message lists what exists when it can.

```lugha
enum Shape { Circle(f64), Square(f64) }

fun main() {
    let s = Shape.Circel(1.0); // error: E0415
}
```

Use a declared variant:

```lugha
enum Shape { Circle(f64), Square(f64) }

fun main() {
    let s = Shape.Circle(1.0);
    match s {
        Circle(r) => println(r),
        Square(w) => println(w),
    }
}
```

Methods work the same way. A struct only has the methods its `impl`
blocks declare:

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 3.0, y: 4.0 };
    println(p.size()); // error: E0415
}
```

```lugha
struct Point { x: f64, y: f64 }

impl Point {
    fun size(self): f64 = self.x * self.x + self.y * self.y;
}

fun main() {
    let p = Point { x: 3.0, y: 4.0 };
    println(p.size());
}
```

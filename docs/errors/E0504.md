# E0504: `break` or `continue` outside a loop

`break` leaves the innermost `loop`, `while` or `for` loop and `continue`
starts its next round (or, with a label, the loop it names). Outside any loop there is nothing for them to act on. A
closure's body counts as outside: a `break` there can't leave a loop in the
function around it.

```lugha
fun main() {
    let n = 3;
    if n > 2 {
        break; // error: E0504
    }
    println(n);
}
```

To leave a function early, use `return`:

```lugha
fun main() {
    let n = 3;
    if n > 2 {
        return;
    }
    println(n);
}
```

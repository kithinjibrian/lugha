# E0332: A program needs OpenSSL, which isn't installed

A program that uses TLS or cryptography — `std.tls`, `std.http` (which
speaks `https://` through `std.tls`) or `std.crypto` — is linked with the
system's OpenSSL. This machine has no OpenSSL development files
(`openssl/ssl.h`, `libssl`, `libcrypto`), so the program can't be built.
Other programs build as before.

```text
import std.crypto; // error: E0332 (on a machine without libssl-dev)

fun main() {
    println(crypto.sha256([]).len);
}
```

Install them and build again:

```text
sudo apt install libssl-dev
```

`lughac check` and the editor don't link, so they never report this.

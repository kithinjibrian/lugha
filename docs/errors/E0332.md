# E0332: TLS needs OpenSSL

A program that uses TLS — `std.tls`, or `std.http`, which speaks
`https://` through it — is linked with the system's OpenSSL. This machine
has no OpenSSL development files (`openssl/ssl.h`, `libssl`), so the
program can't be built. Other programs build as before.

```text
import std.http; // error: E0332 (on a machine without libssl-dev)

fun main() {
    println(http.get("https://example.com/").is_ok());
}
```

Install them and build again:

```text
sudo apt install libssl-dev
```

`lughac check` and the editor don't link, so they never report this.

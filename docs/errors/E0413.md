# E0413: Struct literal missing fields

A struct literal left out one or more of the struct's fields. Lugha has
no default field values, so every field must be given when a struct is
built; that way a value can never have a field that was never set.

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0 }; // error: E0413
    println(p.x);
}
```

Give every field:

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0, y: 0.0 };
    println(p.x);
}
```

If many values share the same defaults, write a function that builds
them:

```lugha
struct Point { x: f64, y: f64 }

fun on_x_axis(x: f64): Point = Point { x: x, y: 0.0 };

fun main() {
    println(on_x_axis(1.0).y);
}
```

# E0414: Struct literal field given twice

A struct literal gives the same field more than once. Only one of the
values could be kept, so rather than pick one silently Lugha reports it.
It is usually a copy-paste slip where another field was meant.

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0, x: 2.0, y: 0.0 }; // error: E0414
    println(p.x);
}
```

Give each field once:

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 1.0, y: 0.0 };
    println(p.x);
}
```

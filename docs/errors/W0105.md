# W0105: A key written twice in a `#{ … }` literal

A `#{ … }` literal gives the same key twice. In a map the later value
wins, so the earlier entry does nothing; in a set the value is there once
either way. Usually a key was mistyped.

```lugha
fun main() {
    let ages = #{"ann": 31, "bo": 40, "ann": 32}; // warning: W0105
    println(ages);
}
```

Keep one entry per key:

```lugha
fun main() {
    let ages = #{"ann": 32, "bo": 40};
    println(ages);
}
```

# E0312: Module not found

An `import` names a module that has no file. `import shapes.circle;` looks
for `shapes/circle.la` next to the importing program's main file (or in
package `shapes`, if `lugha.toml` lists one), and `import std.math;` for a
module of the standard library. When none of these exists, nothing can be
loaded.

```lugha
import std.maths; // error: E0312

fun main() {}
```

Check the module's name; the help lists the std modules:

```lugha
import std.math;

fun main() {
    println(math.max(2, 3));
}
```

For a module of your own, check that the file exists at the path the
import spells, with `/` for each `.`: `import shapes.circle;` needs
`shapes/circle.la` beside the main file. A package name used on its own,
like `import geo;`, is also E0312 unless the package has an entry: a
`lib.la` in its source folder, which `import geo;` then imports (v17).
Otherwise import one of the package's modules, such as `import geo.shapes;`.
The entry has only that name: `import geo.lib;` is E0312 too.

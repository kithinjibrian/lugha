# E0513: A label already used by an enclosing loop

Nested loops can't share a label: `break name;` would be ambiguous. Loops
side by side may reuse one.

```lugha
fun main() {
    scan: for i in 0..3 {
        scan: for j in 0..3 { // error: E0513
            if i + j == 3 {
                break scan;
            }
        }
    }
}
```

Give the inner loop its own name:

```lugha
fun main() {
    rows: for i in 0..3 {
        cols: for j in 0..3 {
            if i + j == 3 {
                break rows;
            }
            if j > i {
                continue cols;
            }
            println("{i}{j}");
        }
    }
}
```

# E0327: A package listed under another name than it declares

A manifest lists a package under a key that differs from the `name` the
package declares in its own `[package]` table. A package's modules are
named after it (`glowworm.array`), and its own examples import it by that
name, so letting each program rename it would give one package different
names in different places.

The example needs two manifests, so it isn't checked as one program:

```text
# lugha.toml (the program)
[packages]
gw = { path = "../glowworm" } # error: E0327

# ../glowworm/lugha.toml
[package]
name = "glowworm"
```

List the package under the name it declares, and use an import alias if
you want a shorter name in your code:

```text
# lugha.toml
[packages]
glowworm = { path = "../glowworm" }

// main.la
import glowworm.array as gw;
```

A package with no `name` can still be listed under any key.

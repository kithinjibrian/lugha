# E0329: `pkg-config` failed for a `[link]` table

A `[link]` table in `lugha.toml` lists `pkg-config` names, and asking the
system `pkg-config` for their flags didn't work. When `lughac build`,
`run` or `test` links the program, it runs `pkg-config --libs` with those
names (and `--cflags` when the table also lists C files). This fails when
`pkg-config` isn't installed, when it doesn't know a name (the library or
its development files aren't installed), or when it prints a flag lughac
doesn't pass on. Only `-l`, `-L` and `-pthread` are taken from `--libs`,
and only `-I`, `-D`, `-pthread` and exactly `-mfpmath=sse`, `-msse` and
`-msse2` (GTK's, which change nothing on x86-64) from `--cflags`, so that no package can
add other options, such as `-Wl,…`, to your build.

The example is a manifest, so it isn't checked as one program:

```text
# lugha.toml, on a system without GTK's development files
[link]
pkg-config = ["gtk4"] # error: E0329
```

Fix what the message names: install `pkg-config` (or `pkgconf`); install
the library's development package (on Ubuntu, `libgtk-4-dev` for `gtk4`);
or, if `pkg-config` gives a flag lughac refuses, list the libraries
yourself with `libs` and `paths` instead. `$PKG_CONFIG` names another
`pkg-config` program. `lughac check` never runs `pkg-config`, so this
error only appears when linking.

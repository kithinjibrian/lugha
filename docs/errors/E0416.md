# E0416: Wrong number of payloads

A variant was built or matched with a different number of payloads than
its declaration gives it. `Rect(f64, f64)` carries two values, so it is
built with two and matched with two names; a variant with no payload
takes no parentheses at all.

```lugha
enum Shape { Circle(f64), Rect(f64, f64) }

fun main() {
    let s = Shape.Rect(1.0); // error: E0416
}
```

Give every payload:

```lugha
enum Shape { Circle(f64), Rect(f64, f64) }

fun main() {
    let s = Shape.Rect(1.0, 2.0);
    match s {
        Circle(r) => println(r),
        Rect(w, h) => println(w * h),
    }
}
```

Patterns need one name, `_` or nested pattern per payload too:

```lugha
enum Shape { Circle(f64), Rect(f64, f64) }

fun width(s: Shape): f64 = match s {
    Circle(r) => r * 2.0,
    Rect(w) => 0.0, // error: E0416
};

fun main() {
    println(width(Shape.Circle(1.0)));
}
```

```lugha
enum Shape { Circle(f64), Rect(f64, f64) }

fun width(s: Shape): f64 = match s {
    Circle(r) => r * 2.0,
    Rect(w, _) => w,
};

fun main() {
    println(width(Shape.Circle(1.0)));
}
```

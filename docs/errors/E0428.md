# E0428: Or-pattern alternatives that bind differently, or `mut` on a variant

An or-pattern, `A | B => …`, runs one arm for several shapes of value. The
arm's body can use a binding only if every alternative gives it a value, of
the same type each time. In `Some(x) | None` there is no `x` when the value
is `None`, so the body couldn't use it.

```lugha
fun main() {
    let o = Some(3);
    match o {
        Some(x) | None => println(x), // error: E0428
    }
}
```

The same error comes from `Count(n) | Size(n)` where one `n` is an `i64`
and the other an `f64`, and from `mut None`: `mut` makes a binding
changeable, and a variant name binds nothing.

Bind the same names, with the same types, in every alternative, or split
the arm:

```lugha
fun main() {
    let o = Some(3);
    match o {
        Some(x) => println(x),
        None => println("nothing"),
    }
}
```

An or-pattern works when the alternatives agree:

```lugha
enum Event { Click(i64), Tap(i64), Close }

fun main() {
    let e = Event.Tap(7);
    match e {
        Click(at) | Tap(at) => println(at),
        Close => println("closed"),
    }
}
```

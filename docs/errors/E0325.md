# E0325: A git package that can't be fetched

lughac couldn't get a git package listed in `lugha.toml`. Fetching runs
the system `git` to find the newest `vMAJOR.MINOR.PATCH` tag that the
entry's `version` accepts and clones it into a per-user cache. It fails
when `git` isn't installed, when a `git` command fails (a wrong URL, no
network, no access; the message shows git's first lines), when no tag
meets the requirement, or under `--offline` when the package isn't both in
`lugha.lock` and in the cache.

The example is a manifest and a repository, so it isn't checked as one
program:

```text
# lugha.toml
[packages]
geo = { git = "https://example.com/geo", version = "3" } # error: E0325

# the repository's tags: v1.0.0, v2.1.0
```

Fix whatever the message names: install `git`; correct the URL; choose a
`version` that one of the tags meets (here `"2"`); or, when working
offline, build once with a network connection so the package is fetched,
cached and locked, and `--offline` builds work from then on.

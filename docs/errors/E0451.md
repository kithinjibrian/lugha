# E0451: A type that doesn't meet a derivable interface

A derivable interface is met through its `derive` blocks: one for a single
type (`i64`, `T[]`), and ones for every `struct`, `enum` or `tuple` whose
parts meet the interface in turn. When some part of a type has no block
that covers it, the type doesn't meet the interface. The message names the
path to that part.

```lugha
interface Show {
    fun show(self): string;
}

derive Show for i64 {
    fun show(self): string = "{self}";
}

derive Show for struct {
    fun show(self): string = "a struct";
}

fun show<T: Show>(x: T): string = x.show();

struct Job {
    id: i64,
    run: fun(i64): i64,
}

fun main() {
    let s = show(Job { id: 1, run: fun(x: i64): i64 = x }); // error: E0451
}
```

Show only the parts that are data, or add a block for the missing type:

```lugha
interface Show {
    fun show(self): string;
}

derive Show for i64 {
    fun show(self): string = "{self}";
}

derive Show for struct {
    fun show(self): string = "a struct";
}

fun show<T: Show>(x: T): string = x.show();

struct JobInfo {
    id: i64,
}

fun main() {
    println(show(JobInfo { id: 1 }));
}
```

A generic function passes its parameter through by asking for the bound:
`fun twice<T: Show>(x: T): string = show(x) + show(x);`.

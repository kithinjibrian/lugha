# E0303: No `main` function

The program has no `fun main`. A Lugha program starts running at `main` in
its main file, so without one there is nothing to run. Only `lughac build`
and `lughac run` report it: `lughac test` runs the program's tests and needs
no `main`, and `lughac check` checks a file without one as a library.

```lugha
// error: E0303
fun greet() {
    println("hello");
}
```

Add a `main` that calls the code you want to run:

```lugha
fun greet() {
    println("hello");
}

fun main() {
    greet();
}
```

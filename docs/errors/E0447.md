# E0447: A file that can't be included

`include_bytes(path)` and `include_str(path)` build a file into the
program when it is compiled. The path is a string literal, relative to the
folder of the `.la` file that names it, with `/` between folders. The file
must be a regular file of at most 16 MiB inside the package's folder: the
folder of the `lugha.toml` that governs the file, or the main file's folder
when there is none. Symbolic links are followed only while they stay inside
it, so a package can't read the other files of whoever builds it. The
message says which rule the path breaks.

```lugha
fun main() {
    let data = include_bytes("../../secret.key"); // error: E0447
    println(data.len);
}
```

A path held in a constant isn't read either: the file is chosen when the
program is written, not computed.

```lugha
const PATH: string = "logo.png";

fun main() {
    println(include_bytes(PATH).len); // error: E0447
}
```

Keep the file in the package, next to the code that uses it, and write its
path in the call:

```lugha
const SOURCE: string = include_str("main.la");

fun main() {
    println(SOURCE.len > 0);
}
```

# E0104: Integer literal too large

An integer literal is bigger than any integer type can hold. The largest
is `u64`'s maximum, `18446744073709551615`; a literal past that can't be
stored anywhere, so Lugha rejects it instead of wrapping it around.

```lugha
fun main() {
    let big = 18446744073709551616; // error: E0104
    println(big);
}
```

If the number really needs to be that large, use a float, which trades
exact digits for range:

```lugha
fun main() {
    let big = 18446744073709551616.0;
    println(big);
}
```

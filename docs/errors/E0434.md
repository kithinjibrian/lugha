# E0434: A misused test

`@test` marks a function that `lughac test` runs on its own. The runner has
nothing to pass it and nothing to do with a result, so a test takes no
parameters, has no type parameters and returns nothing; it passes unless an
`assert` fails or it panics. Tests are also left out of `lughac build` and
`run`, so other code can't call a test or use one as a value.

```lugha
@test
fun doubles(n: i64) { // error: E0434
    assert_eq(n * 2, n + n);
}

fun main() {}
```

Write the inputs inside the test:

```lugha
@test
fun doubles() {
    let n = 21;
    assert_eq(n * 2, n + n);
}

fun main() {}
```

To share code between tests, or call it from `main`, put it in an ordinary
function and call that from each test:

```lugha
fun check_doubles(n: i64) {
    assert_eq(n * 2, n + n);
}

@test
fun doubles_small() {
    check_doubles(2);
}

@test
fun doubles_large() {
    check_doubles(1000000);
}

fun main() {}
```

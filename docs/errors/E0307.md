# E0307: Struct contains itself

A struct holds itself, directly or through other structs. A struct's fields
are stored inline, so a `Node` holding a whole `Node` would need infinite
space. The cycle is reported whether it is one struct or several
(`A -> B -> A`).

```lugha
struct Node { value: i64, next: Node } // error: E0307

fun main() {}
```

Hold it through an `Option`, an enum or an array, which are stored apart
from the struct: an `Option` for a chain, an array for many children.

```lugha
struct Node { value: i64, next: Option<Node> }
struct Tree { value: i64, kids: Tree[] }

fun main() {
    let n = Node { value: 1, next: Some(Node { value: 2, next: None }) };
    let t = Tree { value: 0, kids: [] };
    println(n.value + t.value);
}
```

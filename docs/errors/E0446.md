# E0446: A constant that depends on itself

Constants may use each other in any order, but not in a circle: each is
computed before `main` after the ones it reads, and a circle has no first
one. A constant also reads every constant read by the functions its value
calls, so a circle can pass through functions. The help lists the circle.

```lugha
const WIDTH: i64 = HEIGHT * 2; // error: E0446
const HEIGHT: i64 = WIDTH / 2;

fun main() {
    println(WIDTH);
}
```

Give one of them a value of its own:

```lugha
const HEIGHT: i64 = 10;
const WIDTH: i64 = HEIGHT * 2;

fun main() {
    println(WIDTH);
}
```

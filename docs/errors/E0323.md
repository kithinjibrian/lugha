# E0323: One package name for two folders

Two manifests in one build list the same package name with different
folders. The modules of package `mathx` are named `mathx.…` everywhere in
the program, so `mathx` has to mean one folder for the whole build, or two
different `mathx.vec` modules would collide. Folders are compared after
`.` and `..` are resolved, so `"libs/mathx"` and `"./libs/../libs/mathx"`
are the same.

The example needs several manifests, so it isn't checked as one program:

```text
# lugha.toml (the program)
[packages]
geo = "libs/geo"
mathx = "libs/mathx"

# libs/geo/lugha.toml
[packages]
mathx = "vendor/mathx" # error: E0323
```

Point both entries at the same folder (here `geo`'s entry could be
`mathx = "../mathx"`), or, if they really are different packages, list
one of them under another name.

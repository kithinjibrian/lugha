# E0432: A bad `format` template

`format("…", a, b)` fills each `{}` hole of the template with the next
value. The compiler checks the template against the values when it
compiles, so the template must be a string literal written in the call, it
must have exactly one hole per value, and its holes must be empty `{}`
(named holes like `{x}` are for ordinary strings). A lone `{` must be
written `{{`.

```lugha
fun main() {
    let s = format("{} and {}", 1); // error: E0432
    println(s);
}
```

Give one value per hole:

```lugha
fun main() {
    let s = format("{} and {}", 1, 2);
    println(s);
}
```

When the text is known where it is written, an ordinary string with named
holes does the same job:

```lugha
fun main() {
    let a = 1;
    let b = 2;
    println("{a} and {b}");
}
```

# E0510: A statement changes what contains the place it writes

An assignment works out where it writes, such as `xs[0]`, and what it
writes. If computing the value changes the array or struct holding that
place, for example by pushing to it or clearing it, the place might move or
vanish before the write. Lugha rejects such statements rather than pick an
order.

```lugha
fun main() {
    let mut xs = [1];
    xs[0] = { // error: E0510
        xs.push(2);
        9
    };
    println(xs);
}
```

The same applies to a `mut self` call through an index whose arguments
change the array, as in `gs[0].f(gs.clear())`.

Do the change as its own statement, before or after the assignment:

```lugha
fun main() {
    let mut xs = [1];
    xs.push(2);
    xs[0] = 9;
    println(xs);
}
```

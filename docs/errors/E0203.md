# E0203: Chained comparison or equality

Comparisons and equality don't chain in Lugha: `a < b < c` would compare a
`bool` with `c`, which is never what was meant, so it is rejected instead
of quietly meaning something surprising.

```lugha
fun main() {
    let x = 5;
    if 0 < x < 10 { // error: E0203
        println("in range");
    }
}
```

Join the two comparisons with `&&`:

```lugha
fun main() {
    let x = 5;
    if 0 < x && x < 10 {
        println("in range");
    }
}
```

The same goes for `==` and `!=`. If you do mean to compare the result of a
comparison, add parentheses:

```lugha
fun main() {
    let a = 1;
    let b = 2;
    println((a == b) == false);
}
```

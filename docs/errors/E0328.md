# E0328: One file imported as two modules

The same file was reached under two module paths. Each file is one module
with one name, so its items, types and symbols exist once; loading it twice
under two names would make two incompatible copies of every type in it.
This usually happens in a package with `source = "src"` whose
`src/main.la` imports its sibling both directly and through the package's
own name.

The example needs several files, so it isn't checked as one program:

```text
# lugha.toml
[package]
name = "tool"
source = "src"

// src/main.la
import cli;
import tool.cli as tc; // error: E0328

fun main() {}

// src/cli.la
fun run() {}
```

Import the file under one path only. From inside the package's `source`
folder, use the plain path (`import cli;`); the `tool.…` form is meant for
programs outside it, such as `examples/` and `tests/`.

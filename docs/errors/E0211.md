# E0211: `spawn` without a call, or a malformed `select` arm

`spawn` starts a green thread that runs one call, so a call must follow
it: the function and its arguments, written out. A name alone, a
literal or any other expression is this error.

```lugha
fun work(): i64 = 42;

fun main() {
    let t = spawn work; // error: E0211
}
```

Write the call. To run several statements, call a closure on the spot,
as Go's `go func() { … }()` does:

```lugha
fun work(): i64 = 42;

fun main() {
    let t = spawn work();
    let u = spawn fun() {
        println("in a green thread");
    }();
    println(t.join());
    u.join();
}
```

Each arm of a `select` waits for one of four things: a value from a
channel (`name = c.recv()`), room to send (`c.send(value)`), a timeout
(`after(ms)`), or nothing at all (`default`). Anything else before the
`=>` is this error too:

```lugha
fun main() {
    let c: Chan<i64> = Chan.buffered(1);
    c.send(1);
    select {
        c.recv() => println("got one"), // error: E0211
    }
}
```

Name what `recv` gives, an `Option` that is `None` once the channel is
closed (or `_` to ignore it):

```lugha
fun main() {
    let c: Chan<i64> = Chan.buffered(1);
    c.send(1);
    select {
        m = c.recv() => println("got {m}"),
    }
}
```

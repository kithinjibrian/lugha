# E0315: Unknown bound

A type parameter's bound names something that isn't an interface. A bound
such as `T: Ord` promises what `T` can do, so it must be the built-in
bounds (`Eq`, `Ord`, the operator bounds like `Num`) or an interface. A
struct, an enum or an undefined name can't be a bound.

```lugha
fun largest<T: Hash>(a: T, b: T): T = a; // error: E0315

fun main() {}
```

Use a bound that exists, here `Ord`, for values that can be compared:

```lugha
fun largest<T: Ord>(a: T, b: T): T = if a < b { b } else { a };

fun main() {
    println(largest(3, 8));
}
```

If you meant your own capability, declare it as an interface first:

```lugha
interface Named {
    fun name(self): string;
}

struct Dog {}

impl Dog {
    fun name(self): string = "dog";
}

fun greet<T: Named>(x: T) {
    println("hello, " + x.name());
}

fun main() {
    greet(Dog {});
}
```

# E0506: Assignment into a string

Strings in Lugha are immutable: once made, their bytes never change. That
lets strings be shared freely without copying. So you can't assign to one
of a string's bytes, to its `len`, or loop over it with `for b of mut s`.
`let mut s` only lets `s` be given a whole new string.

```lugha
fun main() {
    let mut s = "hello";
    s[0] = 72; // error: E0506
    println(s);
}
```

Build a new string instead, and assign that:

```lugha
fun main() {
    let mut s = "hello";
    s = "H" + s.slice(1, s.len);
    println(s);
}
```

# E0511: Changing a variable a closure captured

A closure captures the variables it uses by copying their values when it
is made. Changing a captured variable inside the closure would only change
its copy, never the variable outside, which is rarely what was meant, so
Lugha doesn't allow it.

```lugha
fun main() {
    let mut count = 0;
    let inc = fun() { count += 1; }; // error: E0511
    inc();
    println(count);
}
```

Have the closure return the new value, and assign it outside:

```lugha
fun main() {
    let mut count = 0;
    let inc = fun(n: i64): i64 { n + 1 };
    count = inc(count);
    println(count);
}
```

When a closure really needs to change shared state, keep it in a `Ref`,
a shared box that every copy points to:

```lugha
fun main() {
    let count = Ref.new(0);
    let inc = fun() { count.update(fun(n: i64): i64 { n + 1 }); };
    inc();
    inc();
    println(count.get());
}
```

# E0103: Unknown escape sequence

A `\` inside a string starts an escape, and only a few exist: `\n`, `\t`,
`\r`, `\\`, `\"` and `\0`. Any other letter after `\` is an error rather
than being kept as it is, so a typo never silently changes the text.

```lugha
fun main() {
    // error: E0103
    println("C:\data\files");
}
```

To put a backslash in a string, write it twice:

```lugha
fun main() {
    println("C:\\data\\files");
}
```

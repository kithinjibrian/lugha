# W0106: A `let` holding `()`

A `let` binds the result of an expression that has no other value than
`()` — usually a call to a function without a return type, kept as if it
returned something. The binding holds nothing useful.

```lugha
fun log(msg: string) {
    println(msg);
}

fun main() {
    let done = log("hello"); // warning: W0106
    println(done);
}
```

Call it as a statement, or give the function a return type if you meant
it to return something:

```lugha
fun log(msg: string) {
    println(msg);
}

fun main() {
    log("hello");
}
```

If you do mean to hold the `()` (to pass it on as a value, say), write the
type and the warning goes away: `let done: () = log("hello");`. Binding
the literal `()` and `let _ = …` never warn.

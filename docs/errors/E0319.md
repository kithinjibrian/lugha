# E0319: The main file imported

A module, or a package's module, imports the program's main file. The main
file is where the program starts: it holds `main` and is what everything
else is loaded from, so it can't also be one of the modules it loads.
Allowing it would make the main file depend on itself.

The example needs two files, so it isn't checked as one program:

```text
// main.la
import util;

fun limit(): i64 = 10;

fun main() {
    println(util.capped(42));
}

// util.la
import main; // error: E0319

fun capped(x: i64): i64 = if x > main.limit() { main.limit() } else { x };
```

Move what both files need into a module of its own, and import that from
each of them:

```text
// main.la
import util;

fun main() {
    println(util.capped(42));
}

// util.la
import settings;

fun capped(x: i64): i64 = if x > settings.limit() { settings.limit() } else { x };

// settings.la
fun limit(): i64 = 10;
```

Or pass the value in as a parameter, so `util` doesn't need to know where
it comes from.

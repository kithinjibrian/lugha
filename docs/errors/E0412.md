# E0412: Cannot infer an array's element type, `None`'s type, or a type argument

The checker couldn't work out a type from what is written. An empty
array `[]` and a bare `None` say nothing about what they will hold, and a
call to a generic function may not fix all of its type parameters.
Lugha infers types only from what is in front of it, so when that
isn't enough it asks for an annotation instead of guessing.

```lugha
fun main() {
    let xs = []; // error: E0412
    println(xs.len);
}
```

Annotate the binding:

```lugha
fun main() {
    let xs: i64[] = [];
    println(xs.len);
}
```

The same applies to `None`:

```lugha
fun main() {
    let x = None; // error: E0412
}
```

```lugha
fun main() {
    let x: Option<i64> = None;
    println(x.is_some());
}
```

# E0444: A union literal writing other than one field

An `extern union` is C's union: its fields share one place, and only one
holds a value at a time. Its literal writes exactly that one field.

```text
extern union Num { int64: i64, float64: f64 }

fun main() {
    let n = Num { int64: 1, float64: 2.0 }; // error: E0444
}
```

Write the one field you set; reading another reads the same bytes as its
type, as C does:

```text
extern union Num { int64: i64, float64: f64 }

fun main() {
    let n = Num { int64: 1 };
    println(n.int64);
}
```

The examples need an `extern` declaration's C side, so they aren't checked
as programs here.

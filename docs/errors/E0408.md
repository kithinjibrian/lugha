# E0408: Invalid cast

An `as` cast was written between types it can't convert. `as` converts
between numeric types (and between integers and `char`); it can't turn a
`bool` into a number, a number into a `bool`, or a function into anything.
In generic code, `n as T` needs `T` to be bounded by `Num` or `Float`.
These conversions have more than one reasonable meaning, so Lugha asks
you to spell out the one you want.

```lugha
fun main() {
    let ready = true;
    let n = ready as i32; // error: E0408
    println(n);
}
```

Write the conversion out:

```lugha
fun main() {
    let ready = true;
    let n: i32 = if ready { 1 } else { 0 };
    println(n);
}
```

The other direction is a comparison:

```lugha
fun main() {
    let n = 3;
    let nonzero = n != 0;
    println(nonzero);
}
```

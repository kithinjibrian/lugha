# E0206: Nesting too deep

Expressions, blocks, patterns or types are nested more than 256 levels
deep. The parser has a fixed limit so that a pathological input, often
one produced by a program, can't overflow the compiler's stack. Code
written by hand never comes near it.

The example needs 257 levels, too long to show in full:

```text
fun main() {
    let x = ((((((((((((((((( … 257 times … 1 … )))))))))))))))));   // error: E0206
}
```

Break the expression up with `let` bindings or helper functions so that
no single piece nests that deep. If a tool generated the code, change it
to emit intermediate bindings instead of one huge expression.

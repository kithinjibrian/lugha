# E0405: Wrong number of arguments

A function, method or variant was called with more or fewer arguments
than it declares. Lugha has no default or optional parameters, so every
call passes exactly one argument per parameter.

```lugha
fun add(a: i64, b: i64): i64 = a + b;

fun main() {
    println(add(1)); // error: E0405
}
```

Pass every argument:

```lugha
fun add(a: i64, b: i64): i64 = a + b;

fun main() {
    println(add(1, 2));
}
```

# E0305: Unknown type name

A type was written that doesn't exist: no struct, enum, interface or
built-in type has that name here. Usually it is a typo, a type from another
module written without its module name, or `Self` outside an `impl` block
or interface.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p: Pointt = Point { x: 1, y: 2 }; // error: E0305
    println(p.x);
}
```

Write the name as it is declared:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p: Point = Point { x: 1, y: 2 };
    println(p.x);
}
```

A type from another module is written with the module's name, as in
`shapes.Circle`, or imported by name with `import shapes { Circle };`.

# E0509: A place swapped with a part of itself

`swap(a, b)` exchanges the values of two places. If one place lies inside
the other, like a node and one of its children, the swap would put the
value inside itself, which can't be done. So both places must be separate.

```lugha
struct Node { value: i64, kids: Node[] }

fun main() {
    let mut n = Node { value: 1, kids: [Node { value: 2, kids: [] }] };
    swap(n, n.kids[0]); // error: E0509
    println(n.value);
}
```

Swap places that don't contain each other, here the two values:

```lugha
struct Node { value: i64, kids: Node[] }

fun main() {
    let mut n = Node { value: 1, kids: [Node { value: 2, kids: [] }] };
    swap(n.value, n.kids[0].value);
    println(n.value);
}
```

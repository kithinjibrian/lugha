# W0104: `..base` that copies nothing

A struct literal wrote every field and still ends with `..base`. Nothing
is copied from `base`, but it is still evaluated, so the line suggests
something it doesn't do: usually a field was meant to be left out.

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 0.0, y: 0.0 };
    let q = Point { x: 1.0, y: 2.0, ..p }; // warning: W0104
    println(q.x);
}
```

Leave out the fields `base` should supply, or remove `..base`:

```lugha
struct Point { x: f64, y: f64 }

fun main() {
    let p = Point { x: 0.0, y: 5.0 };
    let q = Point { x: 1.0, ..p };
    println(q.y);
}
```

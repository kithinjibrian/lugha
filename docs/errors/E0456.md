# E0456: A deferred statement with a value

A `defer` statement's value would go nowhere, so it must have type `()`.
This stops a deferred `Result` from silently dropping an error.

```lugha
import std.fs;

fun main() {
    defer fs.remove_file("tmp.txt"); // error: E0456
}
```

Handle the error, or discard it on purpose with `;` inside braces:

```lugha
import std.fs;

fun main() {
    defer {
        fs.remove_file("tmp.txt");
    }
}
```

`close()` on files and sockets returns `()`, so `defer f.close();` needs
neither.

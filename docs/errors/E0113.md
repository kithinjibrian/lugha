# E0113: Unterminated block comment

A block comment opened with `/*` never reaches its `*/`. Block comments
nest in Lugha, so every `/*` inside one needs its own `*/` too; that lets
you comment out code that already holds a block comment.

```lugha
fun main() {
    /* the old greeting: // error: E0113
    println("hi");
    println("hello");
}
```

Close the comment:

```lugha
fun main() {
    /* the old greeting:
    println("hi"); */
    println("hello");
}
```

A nested `/*` needs its own close:

```lugha
fun main() {
    /* off for now: /* a note */ // error: E0113
    println("hello");
}
```

```lugha
fun main() {
    /* off for now: /* a note */ */
    println("hello");
}
```

# E0407: `void` used as a value

A call to a function that returns nothing was used where a value is
needed: stored in a binding, passed as an argument, or used in an
expression. A function without a return type gives back no value, so
there is nothing to store.

```lugha
fun log(msg: string) {
    println(msg);
}

fun main() {
    let x = log("hello"); // error: E0407
}
```

Call it as a statement on its own:

```lugha
fun log(msg: string) {
    println(msg);
}

fun main() {
    log("hello");
}
```

If you need a result, give the function a return type and return one.

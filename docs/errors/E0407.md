# E0407: Retired in v17

This code is never reported and will never be reused for anything else.

Before v17, a function without a return type gave back no value at all
(`void`), so using its call as a value — `let x = log("hi");`, or
`println(log("hi"))` — was E0407. Version 17 made `()` a type with one
value (milestone 107): such a function returns `()`, and every expression
has a value. Binding one to a name by mistake is now warning W0106.
